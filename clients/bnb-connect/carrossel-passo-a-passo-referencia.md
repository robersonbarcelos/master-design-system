# BNB Connect — Carrossel "Passo a Passo" já publicado (referência visual + processual)

> Recebido do Diego em 2026-09-10 (8 slides, formato quadrado 1:1 Instagram). Primeiro material visual real da marca que vimos — até então só tínhamos descrição textual dos brand books.

## O que isso confirma sobre a identidade visual (resolve pendências do brand-spec)

- **Logo real, finalmente visto:** ícone de casa em contorno (outline, não preenchido) + wordmark "BNB CONNECT" em duas linhas ("BNB" grande, "CONNECT" menor abaixo, letter-spacing largo). Bate com a descrição dos 2 brand books ("símbolo de casa com ponto central") — o slide 2 mostra a casinha com um quadrado central, confirma o "ponto/quadrado central" descrito nos docs.
- **Cor:** azul petróleo escuro consistente com o #005070 dos brand books, aplicado em título, ícones e fundo de destaque (slide 6 usa o azul escuro como fundo sólido). Fundo geral dos slides é off-white/bege claro, não o #EAF2F5 exato descrito — vale confirmar se é o mesmo fundo claro ou uma variação.
- **Tipografia:** sans-serif bold arredondada para títulos (grande, friendly, não é uma serifada corporativa engessada) e uma sans-serif mais neutra para corpo de texto. Ainda não temos o nome exato da fonte — mas já dá pra ver a família visual (arredondada, moderna, não muito "institucional pesado").
- **Estilo de ícone:** ícones em círculo sólido azul escuro, ilustração line-art branca simples (alvo, relógio, cifrão, gráfico de barras, grupo de pessoas, engrenagem, prancheta, lupa, estrela) — um sistema de iconografia consistente que pode virar padrão para os próximos carrosséis.
- **Foto de imóvel real:** o slide 7 e o slide 1 (capa) usam foto de ambiente (quarto/sala) com tratamento de luz quente, aparência de imóvel real de alto padrão — consistente com a diretriz "fotografia real, sem stock genérico" dos brand books.

## O que isso confirma sobre o processo (mais um terceiro relato do fluxo operacional!)

Agora temos **3 versões do mesmo processo**, cada uma com um número de etapas diferente:

| Fonte | Nº de etapas | Etapas |
|---|---|---|
| V1/V2 (brand books) | 12 | Solicitação de dados → contrato → assinatura → inclusão de co-host → análise → questionário → criação/otimização → Guia da Casa → precificação → análise ao proprietário → ajustes → anúncio publicado |
| Site `/analisar-meu-imovel` | 3 | Você envia dados → nossa equipe avalia → você recebe devolutiva (esse é só o funil do diagnóstico gratuito, não o onboarding completo) |
| Site `/como-trabalhamos` | 6 | Conhecemos o imóvel → Posicionamos → Potencializamos o anúncio → Precificamos → Operamos → Evoluímos sempre |
| **Este carrossel (novo)** | 5 + pós-lançamento | 01 Diagnóstico → 02 Estratégia → 03 Estruturação → 04 Implementação → 05 Go Live → (pós: Monitorar/Ajustar/Otimizar/Evoluir) |

**Leitura:** não é um conflito real — são o mesmo processo de negócio contado em granularidades diferentes para públicos/formatos diferentes (documento interno detalhado vs. site institucional vs. carrossel educativo de Instagram). O carrossel é o formato mais **testado para consumo social** (linguagem simples, 1 ideia por slide, verbo de ação em maiúsculo no rodapé) — deve virar o **modelo de referência estrutural** para carrosséis futuros sobre processo/metodologia, com o conteúdo mais rico dos brand books (Anexo A-F do `positioning-consolidado.md`) usado como banco de informação por trás da copy enxuta.

Frase de fechamento do carrossel vale registrar como possível mensagem-chave nova: **"Porque administrar um imóvel é diferente de operar um negócio."** — não está em nenhum dos brand books nem no site, é original desse carrossel e é uma frase forte de diferenciação (ecoa a "Regra competitiva: não competir apenas por preço. Competir por método..." do V1).

## Uso recomendado

- Tratar este carrossel como **peça aprovada existente** — usar como referência de layout/tom para o `visual-system.md` do cliente quando formos estruturar o padrão de carrossel (grupos visuais, JSON de geração de imagem).
- Copy do carrossel é mais simples e direta do que o texto dos brand books — bom sinal de que a voz para Instagram deve ser mais curta/escaneável do que o tom "institucional" dos documentos estratégicos.
