## VOZ GERAL — DNA DE COPY PARA CARROSSEL

Os carrosseis da Carol operam em dois registros calibrados por linha:

| Registro | Quando usar | Referência base |
|---|---|---|
| **Editorial assertivo** | Produto, peça, detalhe | Lancaster (C4, C5, C7, C8) |
| **Editorial contemplativo** | Identidade, cultura, reflexão | Tayná (C1) + Willian Vipe (C6) |

### Regras universais — nenhuma linha viola

- Sem travessão (—) — nunca, em nenhum slide
- Sem "look do dia", "tendência do momento", "não perca", "transforme"
- Sem trios abstratos ("elegância, sofisticação, leveza") — escolher um e ser específico nele
- Sem perguntas retóricas sem resposta no mesmo slide
- Sem adjetivo sem elemento concreto que o sustente
- Nomear o material, o detalhe, a técnica — nunca generalizar
- Verbos de ação: "transmite", "conversa", "existe", "revela", "traduz", "virou", "mudou"
- Sem "Não é X. É Y." — contraste binário proibido (regra do production-rules.md)

## BLOCO 1 — EDITORIAL DE PRODUTO → converte

> CTA universal deste bloco:
> "Entre em contato para conhecer a peça." / "Marque seu atendimento."

### LINHA A: A PEÇA
*O que a peça é: material, técnica, detalhe, acabamento*

**DNA de referência:** Lancaster sofisticação (C7) + Lancaster Chanel (C5)

**Tom:** assertivo, técnico-sensorial. Nomeia o que os outros não nomeiam. Autoridade vem da precisão, não do superlativo.

**Estrutura de slide:**
```
HEADLINE — o elemento em 2-3 palavras (nunca adjetivo)
          ↓
FRASE 1 — o que esse elemento faz antes do uso
          ↓
FRASE 2 em bold — a experiência que esse elemento cria
```

**Padrão de capa (Lancaster C7 adaptado):**
```
O que faz [esta peça] transmitir [qualidade/autoria]
antes mesmo de vestir?

Spoiler: não é só o design.
```

**Exemplo de corpo de slide:**
```
O tule das mangas

Antes da modelagem, o tule comunica.
Ele cria transparência onde poderia haver peso.

Tecido e estrutura em diálogo: leveza como escolha, não como ausência.
```

**Técnicas ativas:**
- "antes mesmo de" — paradoxo temporal (C7)
- Headline de 2 palavras + 1 frase de setup + 1 frase em bold (C7)
- Materiais que "conversam entre si" (C7)
- "Spoiler:" como hook de capa (C7)

**Framework narrativo:** DEMO WALKTHROUGH — mostra a peça elemento por elemento, como editorial fotográfico em movimento

**CTA:**
```
Esta peça foi produzida em lote reduzido.
Para conhecê-la, entre em contato.
```

### LINHA B: O CORPO
*Como a peça se relaciona com o corpo: silhueta, caimento, movimento, liberdade*

**DNA de referência:** Tayná Tinelo (C1) + Lancaster Chanel (C5)

**Tom:** contemplativo, fluido. Fala do que a roupa liberta, não do que ela marca. Ritmo quebrado com respiração entre ideias. Frases que existem antes de explicar.

**Estrutura de slide:**
```
HEADLINE — paradoxo ou contraste (C5: "O simples virou sofisticado")
          ↓
1-2 frases curtas que respiram
          ↓
1 frase que nomeia o que isso significa para o corpo
```

**Padrão de capa (Tayná C1 + Lancaster C5 adaptados):**
```
Quando o vestido não marca o corpo,
quem fala é a silhueta.
```

**Exemplo de corpo de slide:**
```
A silhueta reta

Não existe para esconder.
Existe para criar espaço.

Espaço entre o tecido e a pele é onde começa a liberdade de movimento.
```

**Técnicas ativas:**
- Paradoxo na capa (C5)
- Frases que respiram, ritmo contemplativo (C1)
- "Antes de X" como contraste fundador (C5)
- Tricolon de adjetivos para descrever o antes: "rígida, pesada, desconfortável" (C5)

**Framework narrativo:** RANT CALLOUT adaptado — confronta a ideia de que roupa precisa marcar para existir

**CTA:**
```
Para experimentar o caimento,
marque seu atendimento.
```

### LINHA C: O LOOK
*O que a peça permite: composições, formas de usar, versatilidade ao longo do ano*

**DNA de referência:** Gabriela Farias (C2) progressão + Lancaster estampas (C4)

**Tom:** claro, progressivo, concreto. Cada slide = uma possibilidade real, não abstrata. Vocabulário emocional-comportamental.

**Estrutura de slide:**
```
HEADLINE — a situação ou composição (não um adjetivo)
          ↓
1 frase de setup: o que a peça faz nesse contexto
          ↓
1 observação sobre o resultado ou sensação
```

**Padrão de capa (Lancaster C4 adaptado):**
```
Um vestido.
Várias possibilidades.

A peça autoral começa com intenção, não com vitrine.
```

**Exemplo de corpo de slide:**
```
Com sobreposição

Uma camisa aberta ou blazer estruturado
transforma a silhueta sem alterar a peça.

A mesma roupa, outro peso, outra estação.
```

**Técnicas ativas:**
- Vocabulário de estados: leveza, equilíbrio, expressão (C4)
- Afirmação temporal "hoje, mais do que nunca" (C4)
- Progressão lógica clara, uma possibilidade por slide (C2)
- Frase-manifesto na capa: "Tendência começa com gente, não com moda" → versão Carol (C4)

**Framework narrativo:** VALUE-STACK — empilha formas de uso crescentes até síntese

**CTA:**
```
Quer conhecer as composições ao vivo?
Agende seu atendimento.
```

### LINHA D: CULTURA DE MODA
*História, referências, o que move a moda, silhuetas que atravessaram épocas*

**DNA de referência:** Lancaster florais (C8) + Lancaster Chanel (C5)

**Tom:** enciclopédico, sereno, autorizado. Conta como alguém que conhece a história e quer compartilhar. Arco histórico com aterrissagem contemporânea.

**Estrutura:**
```
CAPA — "A origem de X / O clássico que atravessa gerações" (C8)
       ↓
S2 — "Tudo começou em..." (âncora de legitimidade em arte, natureza ou necessidade)
       ↓
S3-4 — arco histórico em verbos de transformação: virou, mudou, transformou, introduziu
       ↓
FINAL — "Um clássico que nunca [some] porque..."
       + "porque" com 3 valores que justificam a permanência
```

**Padrão de copy (C5 + C8 adaptados):**
```
Antes do shift dress,
a silhueta feminina precisava marcar o corpo para existir.

Ele mudou essa equação.

Introduziu espaço entre o tecido e a pele
como escolha de design, não como descuido.
```

**Técnicas ativas:**
- "Tudo começou na..." como âncora (C8)
- "Antes de X" como contraste fundador (C5)
- Subtítulo como posicionamento: "O clássico que atravessa gerações" (C8)
- Verbos de transformação sem passiva (C5)
- "Porque" como fechamento com sentido (C8)
- A única exclamação possível: "Um clássico que nunca desaparece!" (C8)

**Framework narrativo:** PROBLEM-PROOF — o "problema" é a moda restritiva; a "prova" é a história

**CTA de conteúdo:**
```
Salva esse post.
```

### LINHA E: MODA AUTORAL
*O que diferencia uma peça autoral, por que a escolha importa, moda como posicionamento*

**DNA de referência:** Duda Vieira (C3) + Lancaster estampas (C4)

**Tom:** argumentativo, inteligente. Usa paralelo de outro setor para provar o ponto em moda. Sem dados científicos — usa padrão histórico como prova. Tem "Ou seja:" como compressor e "Ps.:" como cumplicidade.

**Estrutura:**
```
CAPA — paradoxo ou inversão
       "X deixou de ser Y e passou a ser Z" (C6 adaptado)
       ↓
S2 — paralelo histórico de outro setor (C3):
     "Quando tudo ficou [industrializado], o [artesanal] ganhou valor."
     Repetir 2-3 vezes em anáfora
       ↓
S3-4 — como esse padrão se aplica à moda agora
       ↓
S5 — "Ou seja:" + compressão em 1 frase (C3)
       ↓
FINAL — fechamento com a posição da Carol
       + "Ps.:" como observação de cumplicidade (C3)
```

**Padrão de copy (Duda C3 adaptado):**
```
Quando a moda de massa dominou as vitrines,
a peça com autoria ganhou outro peso.

Não como nicho.
Como posição.

Ou seja: a pessoa que escolhe uma peça autoral
não está comprando uma roupa.
Está comunicando uma escolha.

(Ps.: esse movimento já começou.)
```

**Técnicas ativas:**
- Paralelo histórico como inevitabilidade (C3)
- Anáfora "Quando X, o Y ganhou valor" — repetida 2-3x (C3)
- "Ou seja:" como compressor (C3)
- "Ps.:" como cumplicidade (C3)
- Afirmação editorial assertiva sem precisar provar (C4)

**Framework narrativo:** RANT CALLOUT — confronta a ideia de que moda autoral é nicho ou luxo inacessível

**CTA de conteúdo:**
```
Concorda? Comenta aqui.
```

### LINHA F: IDENTIDADE
*A relação entre a mulher e o que veste. Estilo como linguagem. A peça como reconhecimento.*

**DNA de referência:** Willian Vipe (C6) + Tayná Tinelo (C1)

**Tom:** íntimo, segunda pessoa, emocional. Flui de slide em slide como um único pensamento em desenvolvimento. Fecha com sensação, não com argumento. Lowercase opcional em slides de corpo para criar proximidade.

**Estrutura:**
```
CAPA — afirmação que fala da pessoa, não da roupa
       ↓
S2 — "por um tempo, [a moda prometia X]" (C6 adaptado)
     + "Só que isso mudou." como pivot casual
       ↓
S3-4 — desenvolvimento fluido, sem divisões rígidas
       a pergunta interna da audiência entre aspas (C6):
       "isso é meu?"
       ↓
FINAL — fechamento emocional (C6):
        "ela não sente que está comprando.
         ela sente que reconheceu algo."
```

**Padrão de copy (Willian Vipe C6 adaptado — lowercase intencional):**
```
quando alguém encontra a peça certa,
não está procurando apenas uma roupa.

está tentando responder uma pergunta
mais importante:

"isso é meu?"

e a resposta começa a ser construída
muito antes de experimentar.
```

**Técnicas ativas:**
- Lowercase como intimidade (C6)
- Pensamento do leitor entre aspas (C6)
- "não porque X, mas porque Y" — reverte o mecanismo (C6)
- Ensaio visual contínuo — não listicle (C6)
- Fechamento com sensação pura, não argumento (C6)
- Frases que respiram, ritmo lento (C1)

**Framework narrativo:** STORYTELLING contínuo — ensaio visual, não listicle

**CTA de conteúdo:**
```
Isso já aconteceu com você?
```

## COMO USAR COM carousel-writer-sms

Ao acionar `carousel-writer-sms` para a Carol:

1. Identificar qual linha editorial o carrossel pertence (A / B / C / D / E / F)
2. Carregar o DNA de referência desta linha como contexto de voz
3. Aplicar o framework narrativo correspondente
4. Seguir a estrutura de slide definida neste arquivo
5. Rodar `copy-qa-sms` com as regras de `production-rules.md` ativas

> A linha editorial define O TOM. O framework narrativo define A ESTRUTURA. O production-rules.md define O QUE NUNCA ENTRA.
