## 03 | ESTRUTURA DE COPY POR EDITORIA

### Motor Aberto
```
Hook: o que a oficina encontrou ou fez (fato concreto da bancada)
→ O que isso significa para a moto do cliente
→ CTA: agendar pelo WhatsApp
```

### ABS Explica
```
Hook: pergunta ou sinal que o motociclista reconhece ("Sua moto está dando sinais?")
→ 3 sinais ou 1 explicação simples, uma ideia por slide
→ CTA: salvar o post e chamar a ABS
```

### Peça Certa
```
Hook: o problema que a peça resolve
→ Produto, aplicação (modelos), condição (preço, parcelas, garantia)
→ CTA: chamar no WhatsApp
```

### Antes de Rodar de Novo
```
Hook: o estado em que a moto chegou
→ Diagnóstico e serviço feito
→ Resultado + CTA de agendamento
```
