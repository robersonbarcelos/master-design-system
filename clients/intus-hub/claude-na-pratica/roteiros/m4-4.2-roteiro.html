M4 · Aula 4.2 · AO VIVO · 8 min Crie sua primeira landing page sem código
Cena 1 Setup 30 s
Tela: Claude Code aberto com pasta

Claude Code aberto, pasta de trabalho selecionada. Vamos construir uma landing page do zero agora.

Sem código. Sem template. Só o prompt certo.

Cena 2 O prompt completo 1 min
Tela: Claude Code, digitando o prompt

Esse é o prompt que vou usar. Completo, com todas as partes:

Cria uma landing page em HTML completo para o meu curso online "Claude na Prática". Seções obrigatórias: 1. Hero com headline, subheadline e botão CTA 2. Seção "O que você vai aprender" com 5 tópicos 3. Seção "Para quem é" com 3 perfis 4. Seção de preço com botão de compra 5. Footer simples Estilo: moderno, escuro (dark mode), fonte sans-serif, cor de destaque dourada. Botões CTA: texto "Quero aprender Claude agora" Salva como index.html na pasta raiz.
Cena 3 Claude planeja e executa 1 min
Tela: Claude Code em execução

Olha o que acontece: o Claude mostra o plano antes de executar. Lista o que vai fazer. Pede confirmação.

Você aprova. Ele começa a escrever o código.

Você não escreve nenhuma linha. Você só aprovou o plano.

Cena 4 Abrir no browser ao vivo 1 min 30 s
Tela: browser com index.html aberto

Arquivo criado. Vou abrir no browser.

Abrir index.html no browser

Isso é uma landing page funcionando. Hero, seções, botões, estilo. Do zero. Em menos de 2 minutos.

Você não sabia programar antes dessa aula. Ainda não sabe. E a página existe.

Cena 5 Iteração: pedir ajustes 2 min
Tela: Claude Code

O comportamento mais importante no Claude Code: não precisa reescrever tudo para ajustar.

Vou pedir uma mudança:

"Muda o hero para fundo azul escuro com gradiente. Adiciona uma seção de depoimentos com 3 cards fictícios."

Enviar pedido de ajuste

O Claude atualiza o mesmo arquivo. Não recria. Ajusta.

Recarregar o browser e mostrar o resultado atualizado
Cena 6 Se tiver bug visual 30 s
Câmera frontal

Se aparecer algum bug visual: não edite o código manualmente.

Descreva o que está errado. "Tem um espaço estranho entre o hero e a próxima seção. Corrige isso." O Claude resolve.

Cena 7 O que mais o Claude Code consegue criar 1 min
Câmera frontal ou slide

Landing page é só um exemplo. O Claude Code também cria: scripts de automação, ferramentas internas, bots, APIs simples, sistemas de agendamento, planilhas com lógica complexa.

Qualquer coisa que possa ser descrita em texto, o Claude Code pode construir.
