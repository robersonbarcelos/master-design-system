M3 · Aula 3.3 · PRÁTICA · 7 min Cowork criando arquivos reais
Cena 1 Setup: criar a pasta de trabalho 1 min
Tela: Finder ou Explorer

Essa é a aula mais mão na massa do M3. Faça junto.

Primeiro: cria uma pasta no computador para o Cowork trabalhar. Eu uso Documentos, pasta Claude-Cowork.

Criar pasta ~/Documents/Claude-Cowork/ ao vivo

Agora configure o Cowork para usar essa pasta como área de trabalho. É aqui que os arquivos vão ser salvos.

Cena 2 Demo 1: planilha Excel com dados e fórmulas 2 min
Tela: Cowork aberto

Primeiro arquivo: controle financeiro em Excel. Prompt:

Cria uma planilha de controle financeiro mensal para um criador digital. Colunas: categoria, valor previsto, valor real, diferença. Adiciona 5 categorias de exemplo com valores fictícios e uma linha de total com fórmula SUM automática. Salva como controle-financeiro-julho.xlsx

O Cowork executa. Vou abrir o arquivo gerado.

Abrir o arquivo .xlsx no Excel ao vivo

Isso é um arquivo real. Com dados, com fórmulas, pronto para usar. Não é uma resposta de chat.

Cena 3 Demo 2: documento Word formatado 2 min
Tela: Cowork

Agora Word. Template de relatório:

Cria um documento Word com a estrutura de um relatório de resultados mensais para meu negócio. Inclui: capa, sumário, seção de resultados, seção de próximos passos. Deixa os campos para preencher. Salva como relatorio-julho-template.docx
Abrir o arquivo .docx no Word ao vivo

Template pronto. Estrutura montada. Você só preenche os dados reais.

Cena 4 Como revisar e corrigir sem recriar 1 min
Câmera frontal

Se o arquivo tiver algum detalhe errado — fórmula incorreta, coluna faltando, seção fora de ordem — não precisa pedir para recriar do zero.

Você digita: "Ajusta o arquivo que você criou. Adiciona uma coluna de porcentagem na planilha." Ele corrige o mesmo arquivo.

Isso é diferente de editar manualmente. Você pede, ele resolve.

Cena 5 Ação prática do aluno 1 min
Câmera frontal

Sua vez: pensa em algo que você precisaria criar manualmente. Uma planilha, um relatório, um template de documento.

Escreve o prompt com as quatro partes que aprendemos: Fontes, Objetivo, Formato, Restrições. E delega.

Você acabou de receber um arquivo real em 2 minutos. Isso teria levado 30 minutos fazendo manualmente.
Entregável

O aluno delega uma tarefa real e recebe o arquivo gerado pelo Cowork na pasta local.

Lembretes de gravação
  • Esta é a aula mais mão na massa do M3 — deixar tempo de pausa após cada demo para o aluno tentar.
  • Se o arquivo tiver erro: mostrar como corrigir pedindo ao Cowork, não editando manualmente.
  • PPT: não precisa cobrir se o tempo ficar curto. Citar como possibilidade, focar em Excel e Word.
  • Frase âncora do wow moment: "você acabou de receber um arquivo real em 2 minutos."
