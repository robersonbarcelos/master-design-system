Cena 1 O que é um Plugin no Cowork 1 min
Câmera frontal

Plugin é um pacote de capacidades que você instala no Cowork.

Diferente de Skill, que é uma instrução de comportamento, Plugin traz conectores, fluxos e ferramentas prontas para uma categoria de trabalho.

É como instalar um aplicativo no celular. Você não precisa construir. Você instala e usa.

Cena 2 Onde ficam os Plugins 30 s
Tela: marketplace do Cowork

No Cowork tem uma aba de Plugins com categorias: Marketing, Design, Data, Produtividade e mais.

Plugins são gratuitos no plano Pro. Não é custo extra.

Mostrar o marketplace e as categorias disponíveis
Cena 3 Demo 1: Plugin de Marketing 2 min
Tela: Cowork com Plugin de Marketing ativo

Primeiro: sequência de emails ao vivo. Prompt:

Cria uma sequência de 3 emails de boas-vindas para novos alunos do meu curso online. Tom: acolhedor, motivador. Entregável: documento Word com os 3 emails formatados.

O Plugin processa, usa os conectores que tem disponíveis e entrega um arquivo Word.

Três emails prontos, formatados, com estrutura real. Isso teria levado 30 minutos fazendo manualmente.

Cena 4 Demo 2: Plugin de Design 2 min
Tela: Cowork com Plugin de Design ativo

Agora Design. Prompt:

Cria um briefing de design para o banner de lançamento do meu curso. Inclui: paleta de cores sugerida, tipografia, referências visuais e copy principal.

Resultado: um documento de briefing formatado. Pronto para passar para um designer ou para uma IA de geração de imagem.

Você não fez o briefing. Você delegou.

Cena 5 Demo 3: Plugin de Data 2 min
Tela: Cowork com Plugin de Data ativo

E Data. Vou subir uma planilha de vendas simples.

Subir planilha de vendas

"Analisa esses dados e me dá os 3 principais insights com gráfico."

O Claude lê a planilha, processa os números e gera um relatório com visual. Sem fórmulas. Sem pivot table. Você perguntou, ele respondeu com dados.

Cena 6 Como encontrar e instalar para o seu nicho 30 s
Tela: marketplace com filtro de categoria

No marketplace você filtra por categoria. Encontra o que serve para o seu tipo de negócio, clica em instalar e está pronto para usar na próxima missão.

Entregável

O aluno instala pelo menos 1 Plugin do seu nicho e faz 1 tarefa completa com ele.

Lembretes de gravação
  • Diferença Plugin vs Skill: mencionar rapidamente. Plugin = pacote completo. Skill = instrução de comportamento. Mais detalhes em M4.
  • Plugins são gratuitos no Pro. Deixar isso explícito.
  • Se algum plugin não estiver disponível na conta: adaptar com o que estiver disponível. Não prometer plugins específicos que podem mudar.
  • Ritmo das demos: mostrar prompt, resultado e "o que isso significa" — não parar para explicar cada detalhe técnico.
