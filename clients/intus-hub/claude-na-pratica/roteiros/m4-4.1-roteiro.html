Cena 1 O que é o Claude Code 1 min
Câmera frontal

Chat conversa. Cowork entrega arquivos. Code age.

Claude Code é o modo onde o Claude não só responde. Ele age no seu computador. Cria arquivos, edita código, instala ferramentas, roda comandos.

E o ponto mais importante: você não precisa do terminal para começar. A aba Code do Desktop App já é o Claude Code funcionando.

Cena 2 O loop agêntico 1 min
Slide: loop de 3 etapas

O Claude Code trabalha em loop. Três etapas que se repetem.

Gather context: ele lê os arquivos da pasta para entender o projeto.

Take action: ele age. Cria, edita, instala.

Verify results: ele verifica se funcionou. Se não funcionou, ajusta.

Você vai ver esse loop acontecendo ao vivo nos próximos minutos.

Cena 4 Primeiro comando ao vivo 1 min 30 s
Tela: Claude Code ativo

Vou pedir algo simples para o Claude criar.

Cria um arquivo chamado README.md com uma descrição simples deste projeto: nome e objetivo em 3 linhas.

Olha o que acontece: o Claude mostra o plano. Pede permissão. Executa. Arquivo criado.

Esse é o loop: gather, take action, verify. Aconteceu agora, em tempo real.

Abrir o arquivo README.md criado para confirmar
Cena 5 CLAUDE.md: a memória do projeto 1 min
Tela: editor de texto com CLAUDE.md

Existe um arquivo especial no Claude Code: CLAUDE.md.

É a memória do projeto. Você define quem o Claude é dentro desse projeto, o que pode e não pode fazer, qual o contexto.

Vou criar um agora:

# Projeto: [nome] ## Contexto [Descrição do projeto em 2-3 linhas] ## Regras - Sempre escreva em português - Arquivos gerados devem ir para a pasta /output - Não delete arquivos sem pedir confirmação

Com esse arquivo na pasta, o Claude vai ler antes de qualquer ação. Não precisa repetir o contexto toda vez.

Câmera frontal

Isso é conteúdo do Domínio Claude. Por enquanto, o Desktop App já dá tudo que você precisa para começar.

Lembretes de gravação
  • Enfatizar: "você não precisa do terminal para começar." Isso tira o medo de quem não é técnico.
  • Mostrar o loop agêntico acontecendo na prática: gather, take action, verify. Nomear em voz alta cada etapa.
  • CLAUDE.md: mostrar que é um arquivo de texto simples. Desmistifica a tecnologia.
  • Terminal: citar como teaser para o Domínio Claude. Não entrar em detalhes.
