Cena 1 Skill vs. Plugin: diferença em 60 segundos 1 min
Slide ou doc: tabela comparativa

Já falamos de Plugin no M3. Agora chegamos às Skills.

Plugin é um pacote completo com conectores, fluxos e comandos. Você instala do marketplace do Cowork.

Skill é uma instrução em Markdown. Um arquivo de texto que ensina ao Claude um comportamento específico. Você cria ou baixa. Coloca na pasta certa. E o Claude passa a se comportar de um jeito novo.

Plugin = aplicativo. Skill = instrução.

Cena 2 O que uma Skill faz na prática 1 min 30 s
Câmera frontal

Skill é instrução reutilizável. Você ensina uma vez, usa sempre.

Exemplo: uma skill de copywriter. Você instala e o Claude passa a escrever com aquele estilo específico em todo projeto que tiver essa skill.

Não precisa repetir "escreva no estilo X" toda vez. A skill já carrega isso.

Abrir um arquivo SKILL.md no editor de texto ao vivo

Olha: é um arquivo de texto. Sem código, sem instalação complexa. Markdown simples com instruções de comportamento.

Cena 3 Onde encontrar skills de qualidade 1 min
Tela: browser com sites de skills

Três lugares para encontrar skills prontas:

skills.sh: o maior repositório. Filtrado por categoria.

ClawHub: curado, skills mais testadas.

agentskills.io: foco em automação e produtividade.

Você baixa o arquivo SKILL.md e instala. É isso.

Cena 4 Como instalar uma Skill 1 min 30 s
Tela: Finder ou Explorer com pasta de skills

Quatro passos.

Um: baixar o arquivo SKILL.md da skill que você escolheu.

Dois: colocar na pasta de skills do Claude. No Mac: tilde ponto claude barra skills. No Windows: pasta do usuário ponto claude barra skills.

Três: abrir o Claude Code.

Quatro: chamar a skill pelo nome. "Use a skill [nome] para [tarefa]."

Mostrar a pasta ~/.claude/skills/ com o arquivo instalado

Cena 6 Skill Creator: criar as suas próprias 1 min
Câmera frontal

Existe um fluxo para criar suas próprias skills do zero. É o Skill Creator.

Não vou ensinar aqui. É conteúdo do Domínio Claude, onde tem um módulo dedicado.

Mas se você quiser criar uma skill customizada para o seu negócio específico: é o próximo passo depois deste curso.

Entregável
