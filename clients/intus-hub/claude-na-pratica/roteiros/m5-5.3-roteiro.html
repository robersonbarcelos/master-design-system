Cena 1 O problema que MCPs resolvem 1 min
Slide: diagrama Sem MCP vs. Com MCP

Sem MCP, o Claude só sabe o que você conta a ele. Ele vive dentro da janela de conversa.

Com MCP, o Claude se conecta a ferramentas externas e age dentro delas. Busca na web em tempo real. Lê e escreve no Notion. Faz commits no GitHub.

MCP é o que transforma o Claude de uma IA que responde em um assistente que age nas suas ferramentas.

Cena 2 A analogia que fixa 1 min
Câmera frontal

A melhor forma de entender MCP:

MCP é como um adaptador universal de tomada. Você não troca o aparelho. Só conecta o adaptador e o aparelho passa a funcionar em qualquer lugar.

O Claude é o aparelho. O MCP é o adaptador. A ferramenta externa é a tomada.

Cena 3 Conector vs. MCP: cada um no seu lugar 1 min
Slide: tabela comparativa

Já vimos Conectores no M2. Qual a diferença para MCP?

Conector está no Settings do Claude.ai. Qualquer usuário Pro instala. Plug and play. Google Calendar, Gmail, Airtable.

MCP requer um arquivo de configuração. Instalação mais técnica. Mais poder. Perplexity, Notion, Linear, GitHub.

A regra: se tem botão Connect no Settings, é Conector. Se precisa de arquivo de configuração, é MCP.

Cena 4 Os MCPs mais usados 1 min
Slide: lista dos 5 MCPs

Os cinco MCPs que mais aparecem no dia a dia:

Perplexity: busca na web em tempo real dentro do Claude Code.

Notion: Claude lê e escreve páginas do Notion.

Airtable: Claude acessa e atualiza bases de dados.

Linear: Claude vê e cria tickets de projeto.

GitHub: Claude lê repositórios e faz commits.

Cena 5 Instalar MCPs é o próximo nível 1 min
Câmera frontal

Configurar MCPs requer um arquivo de configuração e um pouco de setup técnico. Não é impossível. Mas está fora do escopo deste curso.

O Domínio Claude tem um módulo dedicado: instalar, testar e usar os MCPs mais relevantes para automação de negócios.

Se você sentiu vontade de instalar pelo menos um agora, é sinal de que está pronto para o próximo nível.

Entregável

Nenhuma ação técnica. O aluno fecha com o conceito claro e o desejo de instalar pelo menos 1 MCP.

Lembretes de gravação
  • Definição para usar e repetir: "MCP é como um adaptador universal."
  • Não entrar em Python, código ou arquitetura técnica de MCP. Zero código nessa aula.
  • Diferença crucial: Conector = Settings, plug and play. MCP = configuração técnica. Deixar isso claro.
  • Encerrar com o convite para o Domínio Claude de forma natural, não abrupta.
