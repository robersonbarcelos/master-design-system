M2 · Aula 2.2 · PRÁTICA · 7 min Projetos com memória: configure uma vez, use sempre
Cena 1 O problema que Projetos resolvem 1 min
Câmera frontal

Você já começou uma conversa no Claude repetindo tudo: quem você é, qual é seu negócio, como você quer que ele responda?

Toda vez do zero. Toda vez o mesmo briefing.

Projeto resolve isso. Você configura uma vez. O Claude lembra em todas as conversas dentro desse Projeto.

Cena 2 Anatomia de um bom Projeto 1 min
Câmera frontal ou slide

Um Projeto bem configurado tem três partes.

Nome: algo que identifica o contexto. "Marketing do Curso", "Consultoria de Vendas", "Conteúdo Semanal".

Instruções: quem você é, qual é o negócio, qual o público, qual o tom de voz, qual o formato de resposta que você prefere.

Documentos de referência: arquivos que o Claude vai usar em toda conversa. Guia de marca, lista de produtos, briefing fixo.

Cena 3 Ao vivo: editar as instruções 2 min
Tela: Projeto aberto no Claude.ai

Vou abrir o Projeto que criamos na aula 1.3 e editar as instruções ao vivo.

Abrir o Projeto e clicar em Editar Instruções

Esse é o exemplo que vou usar:

Você é meu assistente de marketing e criação de conteúdo. Meu negócio: [nome e descrição em 2 linhas] Meu público: [descrição do perfil ideal de cliente] Tom de voz: direto, sem firulas, linguagem acessível Formato padrão: sempre use listas quando for enumerar, evite parágrafos longos Idioma: sempre português brasileiro

Preenche com o seu negócio real. Quanto mais contexto você der aqui, mais preciso o Claude vai ser em todas as suas conversas.

Salvar as instruções
Cena 4 Teste: o Claude já sabe o contexto 1 min 30 s
Tela: nova conversa dentro do Projeto

Agora o teste. Vou abrir uma conversa nova dentro do Projeto — sem repetir nada.

Iniciar nova conversa no Projeto

Pergunta simples: "Quais são os 3 principais erros que o meu público comete?"

Olha a resposta: o Claude já sabe quem é o público, qual é o negócio, qual é o tom. Não precisei explicar nada.

Você não vai mais precisar repetir quem você é toda vez. O Claude já sabe.

Cena 5 Dica avançada: documentos de referência 1 min
Tela: aba de documentos do Projeto

Além das instruções, você pode subir documentos de referência direto no Projeto.

Um PDF com o guia de marca. Um DOCX com a lista de produtos. Um texto com as perguntas frequentes dos clientes.

O Claude vai ler esses documentos em toda conversa dentro do Projeto. Você não precisa colar o conteúdo toda vez.

Cena 6 Ação do aluno 30 s
Câmera frontal

Sua vez: abre o Projeto que você criou, edita as instruções com o contexto real do seu negócio e faz uma conversa sem repetir nada.

Se funcionar como esperado, o Projeto está configurado.

Entregável

Projeto configurado com: descrição do negócio, tom de voz definido, e pelo menos 1 documento de referência adicionado (opcional).

Lembretes de gravação
  • Momento "wow" obrigatório: mostrar conversa SEM Projeto (resposta genérica) e COM Projeto (resposta personalizada). O contraste convence.
  • "Você não vai mais precisar explicar quem você é toda vez. O Claude já sabe." — repetir essa frase.
  • Documentos de referência: PDF, DOCX ou texto colado direto nas instruções. Mostrar ao menos um exemplo.
  • Não confundir com Cowork: Projetos no Chat são memória de contexto. No Cowork, o Projeto tem pasta de arquivos no computador.
