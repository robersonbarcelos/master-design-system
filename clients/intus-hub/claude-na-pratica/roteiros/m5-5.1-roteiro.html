M5 · Aula 5.1 · CONCEITUAL · 6 min O que são agentes e como o Claude se multiplica
Cena 1 O limite do Claude sozinho 1 min
Câmera frontal

O Claude é poderoso. Mas tem um limite quando trabalha sozinho.

Uma conversa, um contexto, um foco de cada vez. Para tarefas longas, paralelas, que envolvem múltiplas fontes de dados, isso vira gargalo.

Agentes resolvem esse limite. E é exatamente isso que esse módulo trata.

Cena 2 A ideia: o Claude chama outros Claudes 1 min
Câmera frontal ou slide com diagrama

Agentes de IA funcionam assim: um Claude orquestrador divide o trabalho e chama outros Claudes para executar partes específicas.

Imagine que você tem um clone seu para cada parte de um projeto. Cada clone tem contexto próprio e foco total na sua tarefa.

O orquestrador coordena. Os subagentes executam. Você recebe o resultado.

Cena 3 Analogia: você com equipe vs. você sozinho 1 min
Slide: comparativo

Você sozinho faz tudo: pesquisa, analisa, escreve. Leva 4 horas.

Com agentes: você passa a missão. O orquestrador divide. Pesquisador coleta. Analista processa. Escritor entrega. Leva minutos.

Não é ficção científica. É o que você vai ver na próxima aula.

Cena 4 Como funciona: orquestrador + subagentes 1 min 30 s
Slide: diagrama

Estrutura padrão de agentes:

Você ↓ Claude Orquestrador ├── Agente 1: Pesquisador (coleta dados) ├── Agente 2: Analista (processa dados) └── Agente 3: Escritor (gera o relatório)

Cada agente tem um contexto separado. Um foco específico. Uma entrega clara.

O orquestrador recebe os resultados de cada um e monta a resposta final para você.

Cena 5 Quando usar e quando é exagero 1 min
Câmera frontal

Quando faz sentido usar agentes: tarefas longas, paralelas, que envolvem múltiplas fontes de dados ou etapas interdependentes.

Quando é exagero: conversas, perguntas rápidas, criar um único arquivo, qualquer tarefa simples. Para isso o Chat ou o Cowork já resolvem.

Agentes são para quando o trabalho é grande demais para uma mente só.

Cena 6 O comando /agents 30 s
Tela: Claude Code com o comando /agents

No Claude Code existe o comando barra agents. Ele lista os agentes disponíveis e permite criar subagentes customizados.

Vou mostrar rapidamente. Os detalhes de criação de agentes customizados são conteúdo do Domínio Claude.

Entregável

Nenhuma ação técnica. O aluno fecha a aula com o conceito claro. Preparado para assistir a demo da próxima aula.

Lembretes de gravação
  • Não usar a palavra "squad". Usar "equipe de agentes" ou simplesmente "agentes".
  • Analogia do clone: "imagine que você tem um clone seu para cada parte do projeto." Usar isso.
  • Diagrama obrigatório na cena 4. Visual simples com setas.
  • Quando NÃO usar agentes: deixar claro que para tarefas simples é exagero. Isso evita frustração de quem tentar usar para tudo.
