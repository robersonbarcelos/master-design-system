M3 · Aula 3.1 · CONCEITUAL · 5 min Como dar uma missão completa: não uma pergunta
Cena 1 O erro mais comum 1 min
Câmera frontal

O erro mais comum de quem começa no Cowork: usar ele como se fosse o Chat.

No Chat você faz perguntas. No Cowork você dá missões.

Dar uma missão ao Cowork é como contratar um assistente por hora. Você não fica conversando. Você passa um briefing claro e ele entrega.

Cena 2 Anatomia de uma missão: 4 partes 2 min
Slide ou doc: as 4 partes

Todo prompt de Cowork que funciona tem quatro partes.

Fontes: quais arquivos ou dados o Claude vai usar. Pasta, planilha, documento específico.

Objetivo: o que precisa ser feito. Criar relatório, analisar dados, montar apresentação.

Formato: como deve ser entregue. Word, Excel, PDF, máximo de páginas, número de seções.

Restrições: tom de voz, idioma, o que não pode entrar, para quem é o documento.

Fontes + Objetivo + Formato + Restrições = missão que funciona.
Cena 3 Prompt ruim vs. prompt bom 1 min
Slide ou doc: comparativo lado a lado

Olha a diferença na prática.

Prompt ruim:

Me ajuda com um relatório de marketing

Prompt bom:

Analisa os arquivos da pasta /relatorios-maio e cria um relatório executivo em Word com: - Resumo de resultados (máx 1 página) - Tabela comparativa mês a mês - 3 recomendações práticas Tom: formal, para apresentar à diretoria Entregável: salva como relatorio-maio-executivo.docx

Mesma tarefa. Resultado completamente diferente. A diferença está no briefing.

Cena 4 Steer mid-run: ajustar sem cancelar 1 min
Câmera frontal

Uma coisa que o Chat não tem: durante uma tarefa no Cowork, aparece um campo para você digitar correções em tempo real.

O Claude está trabalhando. Você vê o progresso. Se quiser ajustar a direção — adicionar uma seção, mudar o tom, cortar algo — você digita ali. Sem cancelar. Sem recomeçar.

Isso se chama steer mid-run. É o diferencial mais prático do Cowork.

Entregável

O aluno escreve o primeiro prompt Cowork para uma tarefa real — usando as 4 partes: Fontes, Objetivo, Formato e Restrições. Vai usar na próxima aula.

Lembretes de gravação
  • Analogia central: "contratar um assistente por hora" — repetir se precisar.
  • Frase âncora obrigatória: "Fontes + Objetivo + Formato + Restrições = missão que funciona."
  • Comparativo ruim vs. bom: tornar o contraste visual e claro — ficar lado a lado na tela se possível.
  • Steer mid-run: mostrar que o campo aparece durante a execução. É diferencial concreto.
