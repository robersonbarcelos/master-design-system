Cena 3 Chat 1 min
Tela: aba Chat

Chat é o modo que todo mundo conhece primeiro. Conversa, perguntas, escrita, brainstorm.

Você digita, ele responde. É o mais direto.

Funciona muito bem para: escrever um e-mail, resumir um texto, tirar uma dúvida, gerar ideias.

O resultado aparece aqui na tela. Texto, tabela, código. Mas é só texto. Não cria arquivo, não age em nada.

Cena 4 Cowork 1 min 30 s
Tela: aba Cowork

Cowork é diferente. Aqui você não manda uma mensagem. Você delega uma missão.

Você dá um briefing, sobe arquivos se precisar, e o Claude vai trabalhar nisso como se fosse um colaborador com prazo e entrega.

A diferença chave: o entregável é um arquivo real. Um Word, um Excel, um PDF. Não só texto na tela.

E tem uma coisa que poucos sabem: você pode intervir no meio da tarefa sem cancelar. Isso se chama steer mid-run. Você vê o Claude trabalhando e pode ajustar a direção em tempo real.

Cena 5 Chat vs. Cowork em 60s 1 min
Slide ou doc: tabela comparativa

Olha essa comparação rápida.

Chat é como mandar uma mensagem. Cowork é como contratar alguém para uma tarefa com prazo e entrega.

Chat: conversa, resultado na tela, você acompanha em tempo real.

Cowork: missão com briefing, trabalha com arquivos, entrega um arquivo real no final.

Quando usar um ou outro? Se você quer trocar ideia ou escrever algo rápido: Chat. Se você quer que o Claude processe um documento, monte uma análise, gere um relatório: Cowork.

Cena 6 Code 1 min 30 s
Tela: aba Code

E o Code é o mais poderoso dos três.

Aqui o Claude não só responde. Ele age no seu computador. Pode criar arquivos, editar código, rodar comandos, abrir programas, instalar ferramentas.

Isso é um agente operando de verdade. Não é conversa, não é entrega de arquivo. É ação direta no sistema.

A maioria das pessoas nunca chega aqui. Vamos passar por isso com calma no M4.

Cena 7 Tabela resumo e quando usar 1 min 30 s
Slide: tabela final

Para fechar: o mapa dos três modos.

Chat: conversas, escrita, perguntas rápidas. Resultado em texto.

Cowork: missões com arquivos, análise, relatório, planilha. Entrega um arquivo salvo.

Code: construir, automatizar, editar código. Ação no seu computador.

Antes de qualquer tarefa, a pergunta certa é: eu quero uma conversa, uma entrega, ou uma ação?

Isso decide o modo.

Entregável
