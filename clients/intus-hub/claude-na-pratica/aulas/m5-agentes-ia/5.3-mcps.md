## Objetivo
O aluno entende o que são MCPs de forma simples — sem código — e sabe quais os mais usados, para quando encontrar o termo não ficar perdido.

## Tópicos em ordem
| # | Tópico | Tempo |
|---|---|---|
| 1 | O problema que os MCPs resolvem: Claude isolado vs Claude conectado | 1 min |
| 2 | O que é MCP: "adaptador universal" — analogia direta | 1 min |
| 3 | Diferença entre Conector (Chat) e MCP (Code): cada um no seu lugar | 1 min |
| 4 | Os MCPs mais usados: Perplexity, Notion, Airtable, Linear, GitHub | 1 min |
| 5 | Como instalar é o próximo nível — teaser para Domínio Claude | 1 min |

## O que o aluno vê na tela
- Diagrama simples:

```
Sem MCP:
Claude ←→ Você (só texto)

Com MCP:
Claude ←→ Perplexity (busca em tempo real)
Claude ←→ Notion (lê e escreve páginas)
Claude ←→ Airtable (lê e cria registros)
Claude ←→ GitHub (lê e commita código)
```

- Comparativo Conector vs MCP:

| | Conector (Chat) | MCP (Code) |
|---|---|---|
| Onde fica | Settings > Integrations | Arquivo de configuração |
| Quem instala | Qualquer usuário Pro | Requer configuração técnica |
| Exemplos | Google Calendar, Gmail | Perplexity, Notion, Linear |
| Complexidade | Baixa | Média-alta |

- Lista dos MCPs mais populares (slide):
  - **Perplexity** → busca na web em tempo real dentro do Claude Code
  - **Notion** → Claude lê e escreve páginas do Notion
  - **Airtable** → Claude acessa e atualiza bases de dados
  - **Linear** → Claude vê e cria tickets de projeto
  - **GitHub** → Claude lê repositórios e faz commits

## Ação final (entregável)
Nenhuma ação técnica. O aluno fecha com o conceito claro e o desejo de instalar pelo menos 1 MCP.

## Notas de gravação
- Definição para usar: "MCP é como um adaptador universal — conecta o Claude a qualquer ferramenta externa sem você precisar programar a integração do zero."
- Não entrar em Python SDK, async/await ou qualquer código. Isso é do curso de MCP oficial (developer).
- Diferença crucial para o aluno: "Conector = plug and play pelo Settings. MCP = conexão mais profunda que requer um arquivo de configuração. Aprender a configurar MCPs é parte do Domínio Claude."
- MCP Inspector: citar como "ferramenta para quem quer testar MCPs" — não demonstrar.
