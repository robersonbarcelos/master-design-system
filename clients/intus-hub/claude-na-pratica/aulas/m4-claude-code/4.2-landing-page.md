## Objetivo
O aluno vê o Claude Code construindo uma landing page funcional em HTML do zero — e entende que consegue criar páginas web reais sem saber programar.

## Tópicos em ordem
| # | Tópico | Tempo |
|---|---|---|
| 1 | Setup: abrir Claude Code com pasta de trabalho | 30 s |
| 2 | Escrever o prompt completo da landing page | 1 min |
| 3 | Claude planeja, pede confirmação, começa a escrever o código | 1 min |
| 4 | Arquivo HTML criado → abrir no browser ao vivo | 1.5 min |
| 5 | Iteração: pedir ajuste de cor, texto ou seção | 2 min |
| 6 | Resultado final: página funcional no browser | 1 min |
| 7 | O que mais o Claude Code consegue criar (lista rápida) | 1 min |

## O que o aluno vê na tela
- Claude Code (Desktop App) com pasta aberta
- Prompt completo sendo digitado:
```
Cria uma landing page em HTML completo para o meu curso online "Claude na Prática".
Seções obrigatórias:
1. Hero com headline, subheadline e botão CTA
2. Seção "O que você vai aprender" com 5 tópicos
3. Seção "Para quem é" com 3 perfis
4. Seção de preço com botão de compra
5. Footer simples

Estilo: moderno, escuro (dark mode), fonte sans-serif, cor de destaque dourada.
Botões CTA: texto "Quero aprender Claude agora"
Salva como index.html na pasta raiz.
```
- Claude mostrando o plano antes de executar
- Arquivo index.html sendo criado
- Abrir index.html no browser: landing page funcionando
- Iteração ao vivo: "Muda o hero para fundo azul escuro com gradiente. Adiciona uma seção de depoimentos com 3 cards fictícios."
- Resultado atualizado no browser

## Ação final (entregável)
O aluno tem uma landing page funcional em HTML rodando no browser local — criada do zero pelo Claude Code em menos de 10 minutos.

## Notas de gravação
- Esta é a aula de maior impacto visual do M4 — o aluno vê uma página real aparecer do nada.
- Mostrar a iteração (ajuste após a primeira versão) — é o comportamento mais importante de aprender no Claude Code: não precisa reescrever tudo, só pede o ajuste.
- Se o HTML ficar com algum bug visual: não editar manualmente — mostrar como pedir ao Claude para corrigir. "Tem um espaço estranho entre o hero e a próxima seção — corrige isso."
- Lista de o que mais o Claude Code cria (30 segundos no final): scripts de automação, planilhas, ferramentas internas, bots, APIs simples, sistemas de agendamento.
- Não prometer que o aluno vai colocar no ar sem hospedagem — é uma demonstração local. Deploy é conteúdo do Domínio Claude.
