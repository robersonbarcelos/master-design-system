## Objetivo
O aluno abre o Claude Code pela primeira vez pela aba do Desktop App — sem terminal, sem instalação — e entende como o loop agêntico funciona na prática.

## Tópicos em ordem
| # | Tópico | Tempo |
|---|---|---|
| 1 | O que é o Claude Code e o que ele faz diferente do Chat e Cowork | 1 min |
| 2 | Loop agêntico: gather context → take action → verify results | 1 min |
| 3 | Abrir o Desktop App → aba Code → selecionar pasta de trabalho | 1 min |
| 4 | Primeiro comando ao vivo: pedir algo simples (ex: criar um arquivo) | 1.5 min |
| 5 | CLAUDE.md: o arquivo de memória do projeto | 1 min |
| 6 | Terminal (Warp/iTerm): citado como próximo nível para quem quiser ir além | 30 s |

## O que o aluno vê na tela
- Claude Desktop App aberto, aba "Code" selecionada
- Seleção de pasta de trabalho (ex: `~/Documents/meu-projeto/`)
- Primeiro prompt ao vivo:
  - "Cria um arquivo chamado README.md com uma descrição simples deste projeto: [nome e objetivo]"
  - Claude: mostra o plano → pede permissão → executa → arquivo criado
- Abrir o arquivo criado para confirmar que existe
- CLAUDE.md ao vivo:
  - "Esse arquivo é a memória do projeto. Você define quem o Claude é, o que pode e não pode fazer, e qual o contexto do projeto."
  - Criar um CLAUDE.md simples ao vivo:
```
# Projeto: [nome]
## Contexto
[Descrição do projeto em 2-3 linhas]
## Regras
- Sempre escreva em português
- Arquivos gerados devem ir para a pasta /output
- Não delete arquivos sem pedir confirmação
```

## Ação final (entregável)
O aluno tem o Claude Code rodando com:
- Pasta de trabalho selecionada
- Primeiro arquivo criado pelo Claude
- CLAUDE.md configurado com contexto do projeto

## Notas de gravação
- Enfatizar: "você não precisa do terminal para começar. A aba Code do Desktop App já é o Claude Code funcionando."
- Loop agêntico (fonte oficial Anthropic — Claude Code 101): "Gather context → take action → verify results." Mostrar isso acontecendo na prática durante o primeiro comando.
- Modos de permissão: mencionar brevemente que o Claude sempre pede confirmação antes de agir (modo padrão). Não entrar em acceptEdits/plan/YOLO — avançado demais para este curso.
