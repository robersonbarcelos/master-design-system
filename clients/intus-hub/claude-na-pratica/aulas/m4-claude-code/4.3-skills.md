## Objetivo
O aluno entende o que é uma Skill, sabe a diferença de Plugin, sabe onde encontrar skills de qualidade e instala o pack exclusivo do curso.

## Tópicos em ordem
| # | Tópico | Tempo |
|---|---|---|
| 1 | Skill vs. Plugin: diferença em 60 segundos | 1 min |
| 2 | O que uma Skill faz na prática: ensinar o Claude uma vez | 1.5 min |
| 3 | Onde encontrar skills de qualidade (skills.sh, ClawHub, agentskills.io) | 1 min |
| 4 | Como instalar uma Skill no Claude Code | 1.5 min |
| 5 | Pack exclusivo do curso: instalar e testar 1 skill ao vivo | 2 min |
| 6 | Skill Creator: o que é e onde aprender a criar as suas | 1 min |

## O que o aluno vê na tela
- Comparativo Skill vs Plugin (slide ou doc):

| | Skill | Plugin |
|---|---|---|
| O que é | Instrução em Markdown (SKILL.md) | Pacote com skills + conectores + comandos |
| Onde fica | Pasta do projeto / ~/.claude/skills/ | Marketplace do Cowork |
| Para que serve | Ensinar um comportamento específico | Adicionar uma capacidade completa |
| Exemplo | "skill de copywriter no estilo X" | Plugin de análise de planilhas |
| Criado por | Qualquer um com um editor de texto | Desenvolvedor ou usuário avançado |

- Sites de skills abertos no browser: skills.sh, ClawHub
- Instalação de uma skill ao vivo:
  - Baixar o arquivo SKILL.md
  - Colocar na pasta `~/.claude/skills/`
  - Testar no Claude Code: "use a skill [nome] para [tarefa]"
- Pack exclusivo do curso:
  - Link de download fornecido nos materiais
  - Instalar 1 skill do pack ao vivo e demonstrar funcionando

## Ação final (entregável)
O aluno tem pelo menos 1 skill do pack exclusivo instalada e funcionando no Claude Code.

## Notas de gravação
- Definição oficial (Anthropic Academy): "Skills são instruções reutilizáveis em Markdown que viajam com o seu projeto — ensine uma vez, use sempre."
- Skill Creator: mencionar que existe um fluxo para criar suas próprias skills (4 formatos: Desktop A/B/C e Terminal D). Não ensinar aqui — é conteúdo do Domínio Claude. "Se quiser criar as suas, é o próximo passo depois deste curso."
- Pack exclusivo: definir antes da gravação quais skills entram (TBD — entre 5 e 10 skills). Exemplos possíveis: skill de copywriter, skill de roteirista, skill de análise de negócios, skill de email marketing.
- Mostrar o SKILL.md de uma skill aberta no editor — é um arquivo de texto simples. Isso desmistifica a tecnologia.
- Troubleshooting: se a skill não funcionar de primeira, mostrar como verificar se o arquivo está na pasta certa. Isso acontece e é normal — fonte: Anthropic Academy, "Troubleshooting skills".
