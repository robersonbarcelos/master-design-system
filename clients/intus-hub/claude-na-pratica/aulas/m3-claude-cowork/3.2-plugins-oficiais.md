## Objetivo
O aluno vê ao vivo como os Plugins do Cowork expandem o que o Claude consegue fazer — e instala pelo menos 1 plugin relevante para o próprio negócio.

## Tópicos em ordem
| # | Tópico | Tempo |
|---|---|---|
| 1 | O que é um Plugin no Cowork (diferença de Skill) | 1 min |
| 2 | Onde ficam os Plugins: marketplace do Cowork | 30 s |
| 3 | Demo 1: Plugin de Marketing — gerar sequência de emails ao vivo | 2 min |
| 4 | Demo 2: Plugin de Design — criar brief de design / moodboard | 2 min |
| 5 | Demo 3: Plugin de Data — analisar planilha e gerar insight | 2 min |
| 6 | Como o aluno encontra e instala plugins para seu nicho | 30 s |

## O que o aluno vê na tela
- Aba Plugins do Claude Cowork
- Marketplace com categorias: Marketing, Design, Data, Produtividade, etc.
- Demo Marketing:
  - Prompt: "Cria uma sequência de 3 emails de boas-vindas para novos alunos do meu curso online. Tom: acolhedor, motivador. Entregável: documento Word com os 3 emails formatados."
  - Plugin processa + entrega arquivo
- Demo Design:
  - Prompt: "Cria um briefing de design para o banner de lançamento do meu curso. Inclui: paleta de cores sugerida, tipografia, referências visuais e copy principal."
  - Entregável: documento formatado
- Demo Data:
  - Subir planilha de vendas simples → "Analisa esses dados e me dá os 3 principais insights com gráfico"
  - Claude processa e gera relatório com visual

## Ação final (entregável)
O aluno instala pelo menos 1 Plugin do seu nicho e faz 1 tarefa completa com ele.

## Notas de gravação
- Diferença Plugin vs Skill (mencionar rapidamente): Plugin = pacote completo com conectores e fluxos prontos. Skill = instrução de comportamento. Mais detalhes em M4.
- Plugin pode ser uma "função isolada" (ex: gerador de email) ou um "pipeline completo" (ex: pesquisa → análise → relatório automático). Fonte: Anthropic Academy, Cowork course.
- Se algum plugin não estiver disponível na conta: adaptar demo com o que estiver disponível. Não prometa plugins específicos que podem mudar.
- Deixar claro: plugins são gratuitos no plano Pro — não é custo extra.
