## Objetivo
O aluno delega uma tarefa real ao Cowork e recebe um arquivo funcional na pasta do computador — Excel, Word ou PPT — sem escrever uma linha de código.

## Tópicos em ordem
| # | Tópico | Tempo |
|---|---|---|
| 1 | Setup: criar pasta de trabalho do Cowork no computador | 1 min |
| 2 | Demo 1: Cowork gerando uma planilha Excel com dados e fórmulas | 2 min |
| 3 | Demo 2: Cowork gerando um documento Word formatado | 2 min |
| 4 | Como revisar o arquivo antes de aprovar | 1 min |
| 5 | Ação prática do aluno: tarefa real com arquivo de saída | 1 min |

## O que o aluno vê na tela
- Pasta local criada: ex. `~/Documents/Claude-Cowork/`
- Cowork configurado para usar essa pasta como área de trabalho
- Demo Excel:
  - Prompt: "Cria uma planilha de controle financeiro mensal para um criador digital. Colunas: categoria, valor previsto, valor real, diferença. Adiciona 5 categorias de exemplo com valores fictícios e uma linha de total com fórmula SUM automática. Salva como controle-financeiro-julho.xlsx"
  - Arquivo criado, abrindo no Excel ao vivo
- Demo Word:
  - Prompt: "Cria um documento Word com a estrutura de um relatório de resultados mensais para meu negócio. Inclui: capa, sumário, seção de resultados, seção de próximos passos. Deixa os campos para preencher. Salva como relatorio-julho-template.docx"
  - Arquivo criado, abrindo no Word ao vivo
- Mostrar o arquivo aberto: "isso é um arquivo real, não uma resposta de chat"

## Ação final (entregável)
O aluno delega uma tarefa real — algo que precisaria fazer manualmente — e recebe o arquivo gerado pelo Cowork na pasta local.

## Notas de gravação
- Esta é a aula mais "mão na massa" do M3 — o aluno deve fazer junto, não só assistir.
- Deixar um tempo de pausa após cada demo para o aluno tentar.
- Se o arquivo gerado tiver algum erro (isso pode acontecer): mostrar como corrigir pedindo ao Cowork para "ajustar o arquivo que você criou" — não precisa recriar do zero.
- Não precisa cobrir PPT nesta aula se o tempo ficar curto — citar como possibilidade mas focar em Excel e Word que são mais universais.
- O "wow moment" desta aula: "você acabou de receber um arquivo real em 2 minutos. Isso teria levado 30 minutos fazendo manualmente."
