## Objetivo
O aluno configura seu ambiente básico: entende o plano certo para ele e cria seu primeiro Projeto com instruções de memória.

## Tópicos em ordem
| # | Tópico | Tempo |
|---|---|---|
| 1 | Pro vs. Free: o que muda na prática (sem enrolar) | 1.5 min |
| 2 | O que é um Projeto e por que ele existe | 1 min |
| 3 | Criar um Projeto ao vivo: nome, instruções, tom de voz | 2 min |
| 4 | Teste rápido: iniciar uma conversa dentro do Projeto | 30 s |

## O que o aluno vê na tela
- Tela de planos do Claude.ai com diferenças destacadas:

| | Free | Pro (US$20/mês) |
|---|---|---|
| Mensagens | Limitadas | Muito mais |
| Acesso a modelos | Haiku | Sonnet + Opus |
| Projetos | Sim | Sim |
| Cowork | Não | Sim |
| Claude Code | Não | Sim |

- Criação de Projeto ao vivo: Settings > New Project > nome > instruções

## Ação final (entregável)
O aluno cria o primeiro Projeto com pelo menos:
- Nome do negócio/uso
- 2-3 linhas de instrução de tom ou contexto
- Uma conversa iniciada dentro do Projeto

## Notas de gravação
- Não empurrar Pro se o aluno é Free — ser honesto: "com o plano gratuito você já consegue acompanhar M1 e M2. Cowork e Code precisam do Pro."
- Nas instruções do Projeto: mostrar um exemplo real. Ex: "Você está me ajudando como consultor de marketing digital. Meu negócio é [X]. Sempre responda em português, tom direto e prático."
- Projetos = memória permanente. O Claude vai lembrar dessas instruções em todas as conversas dentro desse Projeto.
- Conectores (Google, Airtable) NÃO entram aqui — aparecem em M2 aula 2.3 onde fazem sentido prático.
