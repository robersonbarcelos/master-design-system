## Objetivo
O aluno sai com um mapa mental claro dos 3 modos do Claude e sabe, antes de usar qualquer um, qual serve para cada situação — incluindo a diferença rápida entre Chat e Cowork.

## Tópicos em ordem
| # | Tópico | Tempo |
|---|---|---|
| 1 | Abrir o Claude Desktop App ao vivo | 30 s |
| 2 | Mostrar as 3 abas: Chat · Cowork · Code | 1 min |
| 3 | Chat: conversa, perguntas, escrita, brainstorm | 1 min |
| 4 | Cowork: missões completas com arquivos reais — entregável no final | 1.5 min |
| 5 | Chat vs. Cowork em 60s: prós e contras diretos | 1 min |
| 6 | Code: constrói, edita, automatiza — age no seu computador | 1.5 min |
| 7 | Tabela resumo ao vivo + quando usar cada um | 1.5 min |

## O que o aluno vê na tela
- Claude Desktop App aberto, navegando entre as abas Chat / Cowork / Code
- Tabela comparativa (slide ou doc):

| Modo | Melhor para | Resultado |
|---|---|---|
| Chat | Conversas, escrita, perguntas rápidas | Texto na tela |
| Cowork | Missões com arquivos: análise, relatório, planilha | Arquivo salvo |
| Code | Construir, automatizar, editar código | Ação no computador |

- Comparativo Chat vs Cowork:

| | Chat | Cowork |
|---|---|---|
| Formato | Conversa | Missão com briefing |
| Trabalha com arquivos? | Limitado | Sim, lê e edita direto |
| Entregável | Texto | Arquivo real (Word, Excel...) |
| Intervenção no meio? | Sim, sempre | Sim — "steer mid-run" |

## Ação final (entregável)
O aluno escolhe mentalmente: "para o que eu preciso hoje, qual modo eu usaria?" Próxima aula: configurar o ambiente.

## Notas de gravação
- Mostrar ao vivo, não só slide. Abrir cada aba e mostrar brevemente o layout de cada uma.
- No Chat vs Cowork: usar analogia simples — "Chat é como mandar mensagem. Cowork é como contratar alguém para uma tarefa com prazo e entrega."
- "Steer mid-run" no Cowork: mencionar que você pode intervir no meio de uma tarefa sem cancelar — é diferente do Chat onde você precisa recomeçar.
- Não entrar em detalhes técnicos — esse é só o mapa. Os módulos seguintes mergulham em cada modo.
