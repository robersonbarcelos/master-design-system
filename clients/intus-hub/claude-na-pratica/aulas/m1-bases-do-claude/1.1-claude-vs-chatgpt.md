## Objetivo
O aluno entende de forma clara e direta por que o Claude é diferente do ChatGPT — sem precisar usar os dois para perceber.

## Tópicos em ordem
| # | Tópico | Tempo |
|---|---|---|
| 1 | A pergunta que todo mundo faz: "qual a diferença real?" | 30 s |
| 2 | Contexto longo: o Claude lembra muito mais do que o ChatGPT | 1 min |
| 3 | Raciocínio e escrita: mais cuidadoso, mais detalhado, menos alucinação | 1 min |
| 4 | Ecossistema: Chat + Cowork + Code como sistema integrado (não existe no ChatGPT) | 1 min |
| 5 | Para quem o Claude não é a melhor escolha (honestidade) | 30 s |
| 6 | Conclusão: não é sobre qual é melhor — é sobre qual serve pro seu fluxo | 1 min |

## O que o aluno vê na tela
- Tabela comparativa simples (pode ser slide ou doc aberto na tela):

| | Claude | ChatGPT |
|---|---|---|
| Janela de contexto | 200k tokens (~150k palavras) | 128k tokens |
| Ecossistema integrado | Chat + Cowork + Code | Só chat (plugins separados) |
| Foco | Escrita, raciocínio, tarefas longas | Geral, imagem, voz |
| Skills customizadas | Sim (SKILL.md) | GPTs (mais limitado) |

## Ação final (entregável)
Nenhuma ação técnica. O aluno fecha a aula com clareza mental: "entendi por que estou aqui."

## Notas de gravação
- Não falar mal do ChatGPT — posicionar como escolha estratégica, não rivalidade.
- Usar exemplo concreto de contexto longo: "você consegue jogar um roteiro de 80 páginas dentro do Claude e ele lembra de tudo até o final da conversa."
- O diferencial do ecossistema integrado (Chat+Cowork+Code) é o argumento mais forte — nenhum concorrente tem isso.
- Tom: conversacional, como se estivesse explicando pra um amigo.
