## Objetivo
O aluno configura um Projeto completo com instruções de contexto, tom de voz e informações do negócio — e percebe que o Claude passa a responder de forma personalizada sem precisar repetir o briefing a cada conversa.

## Tópicos em ordem
| # | Tópico | Tempo |
|---|---|---|
| 1 | O problema que Projetos resolvem: repetir contexto toda vez | 1 min |
| 2 | Anatomia de um bom Projeto: nome + instruções + tom | 1 min |
| 3 | Ao vivo: editar as instruções do Projeto criado na aula 1.3 | 2 min |
| 4 | Teste: abrir nova conversa no Projeto e ver o Claude "já saber" o contexto | 1.5 min |
| 5 | Dica avançada: adicionar documentos de referência ao Projeto | 1 min |
| 6 | Ação do aluno: completar as instruções do próprio Projeto | 30 s |

## O que o aluno vê na tela
- Projeto aberto no Claude.ai
- Campo de instruções sendo editado ao vivo com exemplo real:

```
Você é meu assistente de marketing e criação de conteúdo.
Meu negócio: [nome e descrição em 2 linhas]
Meu público: [descrição do ICP]
Tom de voz: direto, sem firulas, linguagem acessível
Formato padrão: sempre use listas quando for enumerar, evite parágrafos longos
Idioma: sempre português brasileiro
```

- Abrir nova conversa dentro do Projeto sem repetir nada
- Fazer uma pergunta que exige contexto do negócio e mostrar que o Claude já sabe

## Ação final (entregável)
O aluno termina a aula com o Projeto configurado com:
- Descrição do negócio
- Tom de voz definido
- Pelo menos 1 documento de referência adicionado (opcional)

## Notas de gravação
- Enfatizar: "você não vai mais precisar explicar quem você é toda vez. O Claude já sabe."
- Mostrar um exemplo de conversa SEM Projeto (resposta genérica) e COM Projeto (resposta personalizada) — o contraste é o momento "wow" da aula.
- Documentos de referência: você pode subir um PDF, um DOCX ou colar texto diretamente nas instruções. Útil para briefings, guias de marca, listas de produtos.
- Não confundir com Cowork — Projetos no Chat são memória de contexto. No Cowork, o Projeto tem uma pasta de arquivos no computador.
