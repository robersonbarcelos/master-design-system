01

O que é um Plugin no Cowork

Definição direta

Pacote completo com conectores e fluxos prontos.

Um Plugin pode ser uma função isolada, como um gerador de emails, ou um pipeline completo: pesquisa, análise e relatório automático em uma só missão.

Onde ficam

Marketplace do Cowork.

Dentro do Claude Cowork há uma aba de Plugins com categorias: Marketing, Design, Data, Produtividade e mais. Você navega, instala o que faz sentido para o seu trabalho e usa nas missões.

Demo 1 · Plugin de Marketing

Plugin de Marketing Demo ao vivo
Prompt usado na aula
Cria uma sequência de 3 emails de boas-vindas para novos alunos do meu curso online. Tom: acolhedor, motivador. Entregável: documento Word com os 3 emails formatados.
O Plugin processa e entrega um arquivo Word com os 3 emails prontos: assunto, corpo do texto, CTA. Cada email com tom e objetivo específicos. Pronto para revisar e usar.

Demo 2 · Plugin de Design

Plugin de Design Demo ao vivo
Prompt usado na aula
Cria um briefing de design para o banner de lançamento do meu curso. Inclui: paleta de cores sugerida, tipografia, referências visuais e copy principal.
Documento formatado com todas as seções: paleta com códigos hex, sugestões tipográficas, referências de estilo e copy principal. Entrega o briefing que você passaria para um designer ou usaria no Canva.

Demo 3 · Plugin de Data

Plugin de Data Demo ao vivo
Prompt usado na aula
[subir planilha de vendas] Analisa esses dados e me dá os 3 principais insights com gráfico.
Claude lê a planilha, identifica padrões e gera um relatório com os 3 insights principais acompanhados de visualização. Sem você precisar abrir o Excel ou fazer uma tabela dinâmica.
