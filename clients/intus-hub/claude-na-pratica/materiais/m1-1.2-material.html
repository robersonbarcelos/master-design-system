Os 3 modos: Chat, Cowork e Code.

Essa aula é ao vivo. O Claude Desktop App vai abrir na tela e você vai ver cada modo funcionando antes de precisar escolher um.

São três formas diferentes de trabalhar com o Claude.

02

Chat: rápido, direto, em texto

O que é

Conversa, escrita e brainstorm.

O modo que todo mundo conhece primeiro. Você digita, ele responde. É o mais direto dos três e funciona muito bem para tarefas que resolvem em uma troca de mensagens.

Quando usar

Tarefas que terminam em texto.

  • Escrever ou revisar um e-mail
  • Resumir um texto
  • Tirar uma dúvida rápida
  • Gerar ideias e brainstorm
  • Criar rascunhos para revisar depois
Limite do Chat: o resultado aparece na tela em texto. Não cria arquivo, não age em nada fora da conversa. Para isso existem o Cowork e o Code.
03

Cowork: missão com entregável real

O que muda

Você não manda uma mensagem. Você delega uma missão.

No Cowork você dá um briefing, sobe arquivos se precisar, e o Claude trabalha nisso como um colaborador com prazo e entrega. O resultado não é texto na tela: é um arquivo real. Um Word, um Excel, um relatório.

Steer mid-run

Você pode ajustar no meio da tarefa.

Enquanto o Claude está trabalhando, você consegue intervir e mudar a direção sem cancelar. Isso é diferente do Chat, onde você precisaria recomeçar do zero.

Na prática: você vê o Claude trabalhando e, se algo não está indo bem, redireciona ali mesmo.

05

Code: o Claude age no seu computador

O que é o Code

Não é conversa. Não é entrega de arquivo. É ação direta.

No Code, o Claude opera como um agente no seu sistema. Ele pode criar arquivos, editar código, rodar comandos, abrir programas e instalar ferramentas.

Isso é diferente de tudo que você viu até aqui. Não é texto na tela, não é um arquivo salvo: é o Claude executando dentro do seu ambiente.

O que o Code consegue fazer

Exemplos práticos

  • Criar e editar arquivos no seu computador
  • Escrever e rodar código real
  • Automatizar tarefas repetitivas
  • Construir páginas e ferramentas
  • Instalar e configurar programas
