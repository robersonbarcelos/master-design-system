MCPs: o Claude conectado ao mundo.

MCP é o adaptador universal que liga o Claude a qualquer ferramenta externa. Sem você programar nada do zero. Nesta aula você entende o conceito e conhece os mais usados.

Conceitual · 5 min Perplexity Notion GitHub
Entregável Conceito claro.

Você fecha com o entendimento de MCPs e sabe quais instalar primeiro quando for ao próximo nível.

Definição para usar Adaptador universal.

Conecta o Claude a qualquer ferramenta externa sem programar a integração do zero. É isso.

Não confundir Conector vs. MCP.

Conector: plug and play pelo Settings, qualquer usuário Pro. MCP: arquivo de configuração, requer setup técnico.

Claude isolado responde.
Claude com MCP age dentro das suas ferramentas.

01

O problema que MCPs resolvem

Sem MCP
Claude ↔ Você
(só texto, sem acesso externo)

O Claude só sabe o que você digita. Não acessa o Notion, não vê o GitHub, não busca na web em tempo real. Tudo que ele sabe, você teve que contar.

Com MCP
Claude ↔ Perplexity (busca em tempo real)
Claude ↔ Notion (lê e escreve páginas)
Claude ↔ Airtable (lê e cria registros)
Claude ↔ GitHub (lê e commita código)
Claude ↔ Linear (vê e cria tickets)
02

A analogia que fixa

Para fixar
MCP é como um adaptador universal de tomada. Você não precisa trocar o aparelho. Só conecta o adaptador e o aparelho passa a funcionar em qualquer país.
03

Conector vs. MCP: cada um no seu lugar

Critério
Conector (Chat)
MCP (Code)
Onde fica
Settings > Integrations
Arquivo de configuração
Quem instala
Qualquer usuário Pro

Exemplos
Google Calendar, Gmail, Airtable
Perplexity, Notion, Linear, GitHub
Complexidade
Baixa
Média a alta
A regra prática: se está no Settings e tem um botão "Connect", é Conector. Se precisa de um arquivo de configuração e de um terminal, é MCP. Aprender a configurar MCPs é parte do Domínio Claude.
