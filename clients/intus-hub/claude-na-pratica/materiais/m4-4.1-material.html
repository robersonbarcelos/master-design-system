01

O que o Claude Code faz diferente

Chat e Cowork

Resultados em texto ou arquivo entregue.

Chat responde na conversa. Cowork entrega um arquivo gerado. Nos dois casos, o Claude trabalha dentro de uma janela e passa o resultado para você.

Claude Code

Agente que age diretamente no seu projeto.

O Code abre arquivos, edita código, cria pastas, roda comandos e verifica o resultado. Ele opera dentro do seu projeto como um colaborador técnico que executa, não só sugere.

02

O loop agêntico: como o Claude Code trabalha

1

Gather context

Lê os arquivos do projeto, entende o que existe e planeja o que vai fazer antes de agir.

2

Take action

Executa: cria, edita, deleta ou roda. Sempre mostra o plano e pede confirmação antes de agir.

3

Verify results

Confere se o resultado ficou correto. Se encontrou erro, corrige sozinho antes de marcar como pronto.

Na prática: você vai ver esse loop acontecendo ao vivo durante o primeiro comando. O Claude mostra o que planejou, pede seu ok e executa.
03

Abrir o Claude Code: passo a passo

1

Abra o Claude Desktop App

Se não tiver instalado: anthropic.com/download. A aba Code aparece no menu lateral junto com Chat e Cowork.

2

Clique na aba Code

É só clicar. Não precisa instalar mais nada. A aba Code já é o Claude Code funcionando dentro do Desktop App.

3

Selecione a pasta de trabalho

Escolha uma pasta do seu computador: ex. ~/Documents/meu-projeto/. O Claude Code vai operar dentro dessa pasta. Todos os arquivos criados ficam ali.

4

Primeiro comando ao vivo

Comece com algo simples para ver o loop acontecer: "Cria um arquivo chamado README.md com uma descrição simples deste projeto: [nome e objetivo]"

04

CLAUDE.md: a memória do projeto

O que é

Um arquivo de texto que define o contexto do projeto.

O CLAUDE.md fica na raiz da pasta de trabalho. Toda vez que o Claude Code abre o projeto, ele lê esse arquivo primeiro. É a memória permanente do projeto: quem é o Claude aqui, o que pode fazer e o que não pode.

Exemplo criado ao vivo

Estrutura mínima que funciona.

# Projeto: [nome]
## Contexto
[Descrição do projeto em 2-3 linhas]

## Regras
- Sempre escreva em português
- Arquivos gerados vão para /output
- Não delete arquivos sem pedir confirmação
