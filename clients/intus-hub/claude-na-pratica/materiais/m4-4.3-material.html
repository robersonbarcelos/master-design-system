02

O que uma Skill parece por dentro

Uma Skill é um arquivo de texto simples. Isso não é tecnologia complexa: é uma instrução bem escrita em Markdown que o Claude lê e segue.

# SKILL: Copywriter
## Comportamento
Ao usar esta skill, escreva copy com:
- Foco no benefício, não na feature
- Linguagem direta, sem jargão
- Parágrafos curtos (máx 3 linhas)
- CTA claro no final

## Ativação
Chame com: "use a skill copywriter para [tarefa]"
Por que isso importa

Você desmistifica a tecnologia.

Skills não são magia. São arquivos de texto que qualquer pessoa consegue ler, editar e criar. Ver um SKILL.md aberto no editor deixa isso claro: é uma instrução, não um algoritmo.

Isso também significa que você pode adaptar qualquer skill do pack para o seu contexto específico, editando o texto.

04

Como instalar uma Skill

1

Baixe o arquivo SKILL.md

Do pack exclusivo do curso ou de um dos sites recomendados. É um arquivo de texto comum.

2

Coloque na pasta correta

Para usar em qualquer projeto: pasta global de skills.

~/.claude/skills/

Para usar em um projeto específico: pasta raiz do projeto, junto com o CLAUDE.md.

3

Teste no Claude Code

Digite: "use a skill [nome] para [tarefa]". O Claude confirma que encontrou a skill e executa com aquele comportamento.

4

Se não funcionar de primeira

Verifique se o arquivo está na pasta certa com o nome correto. Isso acontece e é normal. A causa quase sempre é caminho errado ou nome diferente do esperado.
