02

O que é um Projeto e por que ele existe

O problema sem Projeto

Toda conversa começa do zero.

O Claude não sabe quem é você, qual é seu negócio, como você quer receber respostas. Você repete o contexto toda vez. Toda hora. Em cada nova conversa.

A solução

Projeto é a memória permanente do Claude.

Você configura uma vez: quem você é, qual o seu contexto, qual tom de voz você quer. Dentro desse Projeto, todas as conversas já começam com esse conhecimento.

Para fixar
É como ter um colaborador que já te conhece antes de você abrir a boca.
03

Criar um Projeto: passo a passo

1
Onde está

claude.ai · Settings · New Project

No menu lateral do Claude.ai, acesse Settings e clique em New Project. Vai aparecer um campo de nome e um espaço para as instruções.

2
Nome do Projeto

Use algo que represente o uso real.

Exemplos: "Marketing Digital", "Consultoria de Vendas", "Conteúdo para Redes". Não precisa ser perfeito agora. Você edita depois.

3
Instruções: o coração do Projeto

Aqui você ensina o contexto uma vez.

Mínimo que funciona: quem você é, o que faz, como quer receber resposta. Exemplo real usado na aula:

// Instruções do Projeto · exemplo

Você está me ajudando como consultor de marketing digital.
Meu negócio é [descreva aqui].
Sempre responda em português, tom direto e prático.
Não use rodeios.
4
O que mais você pode adicionar

Quanto mais contexto, melhor o resultado.

Público-alvo dos seus clientes, produtos ou serviços que você oferece, o que você nunca quer ver nas respostas, restrições de comunicação. Vai construindo à medida que usa.

04

O teste que comprova: abra uma conversa no Projeto

O que fazer agora

Inicie uma conversa dentro do Projeto recém-criado.

Não fora dele. Dentro. Vai aparecer a opção de escolher o Projeto ao iniciar uma nova conversa.

Pergunta simples para testar: "Qual é o principal desafio do meu negócio?"

O que você vai ver

O Claude responde sabendo o contexto.

Sem você precisar explicar nada. Sem repetir quem você é. Ele já sabe porque as instruções do Projeto foram carregadas automaticamente.

Se a resposta não usar o contexto: revise as instruções. Elas podem estar genéricas demais. Seja mais específico sobre o que você faz.
05

Entregável desta aula

Checklist de conclusão

Você terminou a aula quando:

  • Projeto criado com nome do seu negócio ou uso
  • Instruções escritas: pelo menos 2-3 linhas de contexto e tom
  • Uma conversa iniciada dentro do Projeto
  • O Claude respondeu usando o contexto que você configurou
O que você construiu

Seu primeiro agente personalizado.

Um Projeto com memória não é só uma pasta. É o Claude configurado para o seu trabalho. Nas próximas aulas você vai aprofundar as instruções e conectar ferramentas.
