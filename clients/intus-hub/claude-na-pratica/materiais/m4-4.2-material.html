02

O prompt completo usado na aula

// Prompt digitado no Claude Code

Cria uma landing page em HTML completo para o meu curso online "Claude na Prática".

Seções obrigatórias:
1. Hero com headline, subheadline e botão CTA
2. Seção "O que você vai aprender" com 5 tópicos
3. Seção "Para quem é" com 3 perfis
4. Seção de preço com botão de compra
5. Footer simples

Estilo: moderno, escuro (dark mode), fonte sans-serif, cor de destaque dourada.
Botões CTA: texto "Quero aprender Claude agora"
Salva como index.html na pasta raiz.
O que acontece depois do prompt: o Claude mostra o plano antes de escrever qualquer código. Você vê o que ele vai fazer e aprova. Depois escreve o HTML completo e salva o arquivo.
03

A iteração: ajustar sem refazer

O comportamento mais importante do Claude Code

Você não recomeça. Você pede o ajuste.

Depois da primeira versão no browser, você pede mudanças diretamente. O Claude reabre o arquivo, aplica e salva. Sem você tocar em código.

Exemplo usado na aula:

Muda o hero para fundo azul escuro com gradiente. Adiciona uma seção de depoimentos com 3 cards fictícios após o preço.

O Claude atualiza o index.html e você recarrega o browser. A mudança já está lá.

04

Se tiver bug visual

O que não fazer

Não edite o HTML manualmente.

Se aparecer um espaço estranho, uma cor errada ou algo fora do lugar, não abra o arquivo e corrija na mão. Peça para o Claude corrigir. Ele sabe o que fez e corrige sem quebrar o resto.

Como pedir a correção

Descreva o problema, não o código.

Fale o que você vê: "Tem um espaço estranho entre o hero e a próxima seção. Corrige isso." O Claude identifica a causa no código e ajusta. Você não precisa entender o HTML para isso.
