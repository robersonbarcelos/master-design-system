01

O problema que Artifacts resolvem

Antes dos Artifacts

"O Claude me deu texto. Mas eu precisava de um arquivo."

Você copiava o texto, colava no Word, formatava manualmente, ajustava, e ainda ficava com algo genérico. A resposta estava certa, mas o formato não servia pra nada fora da tela.

Com Artifacts

Output separado da conversa. Pronto para usar.

O resultado aparece no painel lateral: um arquivo real que você baixa, copia ou abre em nova aba. A conversa continua de um lado. O entregável fica do outro.

02

Demo 1: tabela comparativa como Artifact

Demo ao vivo Tabela em Markdown gerada como Artifact
Prompt usado na aula
Cria uma tabela comparando 3 ferramentas de agendamento para criadores digitais.
Formato: tabela Markdown com colunas: ferramenta, preço, melhor para, limitação.
O que aparece na tela

O resultado não aparece dentro da conversa. Ele aparece no painel lateral como Artifact. Você pode copiar a tabela, editar as linhas ou baixar o arquivo, sem precisar reiniciar o chat.

O que observar na tela: o botão de copiar, o botão de baixar e a opção de abrir em nova aba aparecem no canto do painel do Artifact. O Claude fica disponível para continuar a conversa enquanto você usa o entregável.
03

Demo 2: mini-relatório formatado em HTML

Demo ao vivo Relatório HTML com visual pronto
Prompt usado na aula
Cria um mini-relatório de 1 página sobre tendências de IA para criadores de conteúdo em 2025.
Formato HTML bonito.
O que aparece na tela

Um Artifact HTML com visual formatado. Títulos, listas, seções, cores. Você abre em nova aba no navegador e já tem uma página pronta para apresentar ou compartilhar.

Ponto de atenção: o Artifact HTML não é uma página publicada na internet. É um arquivo local que você pode abrir no navegador, salvar ou adaptar. Para publicar, é outro passo.
04

Tipos de Artifact que o Claude gera

📝
Markdown
Textos formatados, tabelas, listas. Ideal para documentos.
🌐
HTML
Páginas com layout visual. Relatórios, apresentações simples.
💻
Código
Python, JavaScript, SQL. Pronto para copiar e rodar.
🎨
SVG
Gráficos vetoriais simples, ícones, diagramas básicos.
⚛️
React
Interfaces interativas, calculadoras, mini-aplicativos.
Para a maioria dos usos: Markdown e HTML resolvem. React e SVG entram quando você quer interatividade ou visual mais elaborado. Não precisa saber programar para pedir.
05

O que você faz com um Artifact

Ações disponíveis no painel

Três botões que mudam o fluxo.

No canto do painel do Artifact você tem as opções diretas:

Copiar Baixar Abrir em nova aba
O que não muda

A conversa continua inteira enquanto você usa o Artifact.

Você pode pedir ajustes, pedir uma versão diferente ou começar outra coisa. O painel fica do lado, disponível. Não precisa copiar antes de continuar.
