# Análise Competitiva — Mercado de Cursos Claude/IA no Brasil
**Produto em desenvolvimento:** Domínio Claude (Intus Hub)
**Data:** Julho 2026
**Metodologia:** Scraping via Chrome de 11 produtos concorrentes

---

## Resumo Executivo

O mercado de cursos Claude no Brasil está segmentado em três camadas:

- **Camada 1 — Kits de prompts (R$27–R$97):** entregam prompts/templates prontos, não ensinam o sistema
- **Camada 2 — Cursos (R$197–R$297):** ensinam Claude Code mas sem cobertura completa ou foco em negócios
- **Camada 3 — Formações premium (R$1.800+):** ensinamento profundo mas inacessível para a maioria

**Gap central:** nenhum produto na faixa R$300–R$700 ensina Chat + Cowork + Code como sistema integrado para empreendedores/criadores, com Skills, MCPs e acesso vitalício.

## Gaps de Mercado Identificados

### Gap 1: Faixa R$300–R$700 vazia para curso COMPLETO
- Mestres.ai (R$297) cobre tudo mas sem ementa pública, sem mentoria
- CloudCoding (R$197) cobre bem mas foco em conteúdo/virais, 1 ano apenas
- Nosso R$497 + vitalício + mentoria + foco em negócios: posição única

### Gap 2: Mentoria ao vivo acessível
Nenhum concorrente oferece mentoria ao vivo abaixo de R$1.800. EscoladeAutomação oferece ao vivo mas como imersão (sem acesso posterior).

### Gap 3: Skills criadas e monetizadas — não só instaladas
Todos os kits vendem skills prontas. EscoladeAutomação ensina a criar. Ninguém ensina a **monetizar skills como produto** em profundidade.

### Gap 4: MCPs + Squads de Agentes no contexto de negócios
CloudCoding e NoCodeStartup cobrem MCPs, mas para apps/dev. Ninguém ensina MCPs para gestão de negócios, CRM, marketing no nível que o nosso público precisa.

### Gap 5: Público infoprodutor/criador especializado
CloudCoding (virais) e copyclaude (copy) atendem parcialmente. Nenhum curso tem posicionamento explícito: "para quem vende infoprodutos, mentorias e serviços digitais".

### Gap 6: Sistema integrado (não ferramenta isolada)
Todos ensinam Claude Code **ou** Chat **ou** Cowork. Nenhum ensina os 3 como sistema: "Chat para capturar, Cowork para executar, Code para construir".
