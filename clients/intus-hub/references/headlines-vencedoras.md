# Headlines Vencedoras — Intus Hub

> Banco de referência extraído de 31 capas vencedoras (Diego Spanevello, IntusCripto, ETER, Brands Decoded, Knowledge Lab e outros).
> **Uso obrigatório:** antes de entregar qualquer variação de gancho para Intus Hub, cotejar contra os padrões aqui. O hook entregue deve ter o mesmo nível de especificidade e força dos exemplos abaixo — nunca abaixo disso.

---

## COMO USAR ESTE ARQUIVO

**Ordem obrigatória — este gate roda ANTES de propor os 3 ângulos, nunca depois:**

1. **Gate de Gancho de Capa** (definido em `clients/intus-hub/CLAUDE.md`) roda logo após o Gate de Vinculação ao Produto — 7 dos 11 padrões selecionados, 3 variações cada, usuário escolhe 1
2. O gancho aprovado entra travado no briefing
3. Só então `narrative-framework-sms` e `carousel-writer-sms` FASE 1 modelam os 3 ângulos — **em torno do gancho já aprovado**, nunca propondo um gancho novo

**No `narrative-framework-sms`:** ao identificar a tensão do conteúdo (Passo 1.5), o gancho já vem definido pelo gate anterior — usar como ponto de partida fixo, não gerar variação nova.

**No `carousel-writer-sms` FASE 1:** o Slide 1 usa o gancho já aprovado. A verificação contra os 11 padrões é apenas uma checagem de segurança — se por algum motivo o gancho aprovado não bater com nenhum padrão (não deveria acontecer, já que ele veio de um dos padrões), sinalizar e não prosseguir.

**Critério mínimo de aprovação:** o hook deve ser específico o suficiente para que o leitor visualize o que vai ver dentro do carrossel — sem precisar clicar. Se o leitor não consegue visualizar, o hook é genérico demais.

## OS 11 PADRÕES IDENTIFICADOS

---

### PADRÃO 1 — DECLARAÇÃO DE RUPTURA
**Fórmula:** `[Verbo de ruptura] + [sujeito conhecido] + [consequência]`
**Verbos de ruptura:** destruiu, virou, acabou de, lançou, fechou, derrubou, revelou

**Exemplos reais:**
```
O Claude destruiu a cripto Zcash. Apenas 1 prompt... -50% em 24 horas.
```
```
Solana acabou de virar uma bolsa de valores.
```
```
O maior cliente dos EUA acabou de fechar a conta.
```
```
A Anthropic lançou o Fable 5. Você não imagina do que ele é capaz.
```

**Como funciona:** declara o fato, não explica. O leitor arrasta para entender o que aconteceu.

**Adaptações para Intus Hub (IA aplicada):**
- "[Empresa real] usou agente de IA para [ação inesperada]."
- "O Aspira acabou de assumir [função que o Diego fazia]."
- "A Anthropic acaba de lançar [X]. Seu agente precisa se atualizar."

---

### PADRÃO 2 — DADO DUPLO EM ESCADA
**Fórmula:** `[Setup com dado 1] + [Virada com dado 2 mais chocante] + [Amplificador de tempo]`

**Exemplos reais:**
```
Pesquisadores colocaram 5 IAs numa simulação de vida ou morte.
400 rodadas depois: a IA mais usada no mundo mentiu em 96% das vezes.
```
```
A Prefeitura do Rio gastou R$500 MIL numa IA "própria".
A internet provou, com matemática, que era um clone.
Em menos de 24 horas.
```

**Como funciona:** primeiro dado cria contexto. Segundo dado entrega o choque. Tempo no final amplifica o absurdo ("e em quanto tempo?").

**Adaptações para Intus Hub:**
- "Testei [N] agentes de IA no mercado. [N específico] horas de teste. [Resultado chocante específico]."
- "[Empresa] investiu R$[valor] numa solução de IA. [O que o Aspira faz] por R$87,90."

---

### PADRÃO 3 — "ACHEI" + DADO DE ESCALA + ENTREGA DIRETA
**Fórmula:** `Achei [objeto com dado de escala] que [benefício concreto]. [Qualificador: Grátis / Open Source / Em menos de X].`

**Exemplos reais (todos do Diego — padrão de voz própria):**
```
Achei um repositório com 62 mil estrelas que dá ao seu agente de IA olhos para ver a internet inteira. Grátis.
```
```
Achei um repositório com 118 mil dados financeiros de graça pra treinar sua IA.
```
```
Achei uma ferramenta de IA Open Source que analisa, testa e executa trades.
Ações, cripto, futuros. Você digita a estratégia, ele testa.
```
```
Achei um projeto open source que une todos os seus Google Drives em um só dashboard.
```

**Como funciona:** "Achei" é voz pessoal — o Diego funcionando como repórter de si mesmo. Dado de escala (estrelas, registros, usuários) valida antes de qualquer copy. Benefício concreto fecha. Sem hype, sem adjetivo vago.

**Regra:** o dado de escala deve ser real e verificável. Nunca inventar o número.

**Adaptações para Intus Hub:**
- "Achei uma forma de dar memória persistente ao seu agente em [tempo específico]."
- "Achei o repositório que o Aspira usa pra nunca esquecer um cliente."

---

### PADRÃO 4 — CONTRASTE TEMPORAL ("Enquanto você... / X já...")
**Fórmula:** `[Enquanto você ainda faz X antigo] + [Aconteceu Y que muda tudo]`

**Exemplos reais:**
```
Enquanto você ainda usa IA pra responder perguntas...
A Anthropic lançou o Fable 5.
```
```
Esses robôs já estão ganhando dinheiro sozinhos.
E já faturam mais que você.
```

**Como funciona:** posiciona o leitor como atrasado sem ofender — o problema é o mercado, não ele. Urgência real, sem contagem regressiva falsa.

**Adaptações para Intus Hub:**
- "Enquanto você ainda configura prompts no ChatGPT, [aluno do Diego] já tem um agente com memória de 6 meses operando no WhatsApp."
- "Você ainda está no chat. Eles já estão em agentes."

---

### PADRÃO 5 — PERGUNTA DE CONFRONTO DE CRENÇA
**Fórmula:** `[Afirmação provocadora sobre grupo ou comportamento] + ?`
**Variante com subtítulo:** `[Pergunta] + [Subtítulo que aprofunda a tensão — nunca responde]`

**Exemplos reais:**
```
CRIAR CONTEÚDO É A NOVA CORRIDA DOS RATOS?
Subtítulo: Entenda como o sonho da liberdade digital virou uma esteira que nunca desliga.
```
```
O BRASILEIRO É VICIADO EM MENTIRAS?
Subtítulo: Entenda por que o sistema recompensa quem mente bem, enquanto quem trabalha de verdade segue invisível.
```
```
A NOVA JUVENTUDE NÃO GOZA E NEM AMA?
```

**Como funciona:** a pergunta confronta uma crença ou um comportamento de grupo. Não ataca indivíduo. Nunca responde na capa — o leitor arrasta para saber.

**Adaptações para Intus Hub:**
- "O mercado de IA virou um camelô digital?"
- "Você realmente precisa de 50 agentes de IA?"
- "Agente de IA é pra programador?"

---

### PADRÃO 6 — ANALOGIA COM MARCA CONHECIDA
**Fórmula:** `[Produto desconhecido] quer ser o [marca conhecida] de [categoria]`
**Variante:** `[Produto desconhecido] = o [apelido popular] de [categoria]`

**Exemplos reais:**
```
A Pendle quer ser o Nubank dos rendimentos.
E está conseguindo.
```
```
O maior agiota do mundo cripto.
$10 bilhões em 9 meses.
```

**Como funciona:** compara o desconhecido com o que o leitor já conhece. Reduz fricção cognitiva. O dado depois da analogia confirma que não é hype.

**Adaptações para Intus Hub:**
- "O Aspira é o funcionário que nunca falta, nunca tem mau humor, nunca pede aumento."
- "IDENTITY.md é o RG do seu agente. Sem ele, ele é ninguém."

---

### PADRÃO 7 — REVELAÇÃO COM SEGUNDO GOLPE
**Fórmula:** `[Fato revelado: risco ou novidade que o leitor não sabia] + [Segundo golpe: implicação pessoal]`

**Exemplos reais:**
```
A chave Pix do Bitcoin está exposta.
E você não sabia.
```
```
Sua mãe vai usar cripto no WhatsApp sem saber.
```

**Como funciona:** revela algo real. Depois golpeia o ego do leitor diretamente — ele estava no escuro. Cria urgência sem hype porque a consequência é real.

**Adaptações para Intus Hub:**
- "Seu agente está esquecendo tudo entre conversas. E você achava que ele lembrava."
- "A maioria dos agentes de IA não tem identidade. É um prompt enrolado em ilusão. E você pagou por isso."

---

### PADRÃO 8 — IRONIZAÇÃO DO RÓTULO OFICIAL
**Fórmula:** `[Ação real + dado] + [e chamam isso de + rótulo oficial irônico]`

**Exemplos reais:**
```
Vão congelar 1 milhão de Bitcoin do Satoshi Nakamoto.
E chamam isso de proteção.
```

**Como funciona:** repete a justificativa oficial e deixa a ironia falar sozinha. Sem precisar dizer que está errado — o leitor conclui.

**Adaptações para Intus Hub:**
- "50 agentes prontos pra você nunca usar. E chamam isso de produtividade."
- "Um prompt de 200 palavras. E chamam isso de agente."

---

### PADRÃO 9 — PROGRESSÃO DE NEGAÇÕES + RESULTADO
**Fórmula:** `Não tem [A]. / Não tem [B]. / E já [resultado concreto com número].`

**Exemplos reais:**
```
Ele não tem chefe.
Não tem funcionário.
E já fez R$1 milhão.
```
```
Esses 5 repos sobem de nível.
[Sub: "Seu agente é bom?"]
```

**Como funciona:** nega o modelo tradicional em escada — cada negação aumenta a curiosidade. O resultado no final é o punchline que valida tudo.

**Adaptações para Intus Hub:**
- "O Aspira não tem mau humor. Não tem hora de almoço. Não esquece nada. E opera 24/7."
- "Sem servidor. Sem código. Sem programador. Agente no ar em menos de 5 minutos."

---

### PADRÃO 10 — NOME REAL + AÇÃO INESPERADA
**Fórmula:** `[Nome que o leitor reconhece] + [verbo] + [ação que ninguém esperava]`

**Exemplos reais:**
```
A Natura usou Prompt Injection para tentar ganhar um processo.
```
```
Vozinha vira garoto-propaganda do novo Homem-Aranha após se tornar o herói improvável da Copa de 2026.
```
```
Os jovens de hoje nunca vão entender o que foi a 1Kilo.
```
```
Não é só talento. O Brasil chegou às oitavas com 3 camadas de IA rodando em paralelo.
```

**Como funciona:** o nome familiar cria atenção imediata. A ação inesperada cria tensão. A capa não resolve — o carrossel resolve.

**Adaptações para Intus Hub:**
- "A [empresa brasileira conhecida] usou agente de IA para [ação concreta]."
- "O Denys (Conset Capital) configurou o agente numa tarde. Roda sem parar desde então."

---

### PADRÃO 11 — CONHEÇA O ESTUDO / DADO HISTÓRICO
**Fórmula:** `Conheça [o estudo / o dado] que [revelou / provou] que [fato chocante + âncora temporal].`

**Exemplos reais:**
```
Conheça o estudo que revelou que pela primeira vez em 100 anos o Q.I da população diminuiu.
Sub: "Os jovens estão mais idiotas."
```
```
O filme que quebrou todos os recordes.
Sub: "Conheça o fenômeno por trás de Michael (2026)."
```

**Como funciona:** âncora temporal ("pela primeira vez em 100 anos", "pela primeira vez desde...") amplifica o dado. O estudo confere autoridade — não é opinião, é dado.

**Adaptações para Intus Hub:**
- "O primeiro agente de IA com memória persistente testado por 6 meses. O que mudou."
- "Pela primeira vez, um agente de IA operou uma operação inteira sem intervenção humana. Aqui está o que aconteceu."

## PADRÃO DE VOZ DO DIEGO — POSTS ESTILO TWITTER

Identificado em 6 posts do próprio Diego. Estrutura canônica:

```
[Frase 1: fato simples, sem adjetivo. Dado bruto.]

[Frase 2: bold. Uma ou duas palavras. O resultado — específico.]
[Frase 3: detalhe técnico ou aplicação.]
```

**Regras do padrão:**
- Sem emojis na capa
- Sem travessão
- Sem adjetivo vago antes do dado
- Tom de repórter de si mesmo — não de especialista dando lição
- O número está sempre no primeiro parágrafo — não no segundo
- A palavra em bold é substantivo concreto, nunca adjetivo

**Exemplos canônicos:**
```
Achei um repositório com 62 mil estrelas que dá ao seu agente de IA olhos para ver a internet inteira.

Grátis.
```
```
Pesquisadores colocaram 5 IAs numa simulação de vida ou morte.

400 rodadas depois: a IA mais usada no mundo mentiu em 96% das vezes.
```
```
A Prefeitura do Rio gastou R$500 MIL numa IA "própria".

A internet provou, com matemática, que era um clone.

Em menos de 24 horas.
```

## O QUE NÃO ESTÁ NESTE BANCO (proibido para Intus Hub)

Nenhuma das 31 capas vencedoras usa:
- Abertura com "Aprenda como...", "Descubra como...", "Saiba como..."
- Adjetivo antes de dado ("incríveis resultados", "poderosa ferramenta")
- Promessa vaga sem número ("vai mudar sua vida", "resultados extraordinários")
- Pergunta retórica sem tensão ("Quer crescer no digital?")
- Tom motivacional ("Você pode fazer isso!")
- Três atributos em lista separados por vírgula sem dado ("Rápido, simples, eficiente.")

Qualquer hook que use qualquer um desses padrões deve ser reescrito antes de ser entregue.
