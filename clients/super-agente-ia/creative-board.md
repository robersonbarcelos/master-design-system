## NOTAS DE PRODUÇÃO POR TIPO VISUAL

### Formatos de documento (recibo, boleto, bula, contrato)
- Tipografia: Inter Tight Black para títulos de seção + Inter Regular para corpo
- Fundo: `#0a0a0a` com superfície de card `rgba(255,255,255,0.04)` imitando papel
- Alternativa impactante: fundo do "documento" em branco sujo `#f5f0eb` sobre fundo preto — cria contraste visual forte e quebra o padrão dark
- Linhas divisórias: `rgba(232,64,0,0.3)` ou branco 15% de opacidade
- Sempre: logo/wordmark SUPER AGENTE IA no canto inferior (nunca logo INTUS HUB dentro da arte do criativo)

### Formatos de UI (pop-up, terminal, loading, log)
- Replicar fielmente a UI real que o formato imita
- Terminal: fonte mono branca/verde claro sobre `#0a0a0a`
- Pop-up: borda cinza escuro, botões estilo OS, sombra sutil
- Loading bar: fill gradiente `#FF6020 → #E84000`
- Impacto vem da fidelidade visual — quanto mais real, mais stopa o scroll

### Formatos de mídia (manchete, trending, placar)
- Manchete: fonte serifada editorial, manter layout de jornal reconhecível
- Trending: replicar layout X/Twitter com precisão de ícones e cores
- Placar: cores de time — usar laranja como cor do time vencedor
- Regra: esses formatos funcionam pelo reconhecimento imediato — não estilizar demais

### Formatos de contraste (split, dois tipos, comparativo)
- Split: linha divisória laranja `#E84000` no centro
- Tipografia grande Inter Tight Black — texto é o visual
- Espaço negativo generoso — não encher o card
- Lado negativo: texto-muted `rgba(255,255,255,0.4)` · Lado positivo: branco puro

### Formatos de autoridade (quote Diego, currículo, crachá)
- Foto Diego: sempre fundo escuro + rim light azul `#1E4D9B`
- Crachá/currículo: manter estilo professional corporate — não gamificar
- Quote: aspas em laranja `#E84000` + texto branco + assinatura menor
