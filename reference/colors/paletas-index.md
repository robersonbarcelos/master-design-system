## Como Usar

- Cada paleta tem um **mood** definido — usar como guia de seleção por tom de comunicação
- Paletas podem ser combinadas entre si quando os modos são complementares
- Para vincular a um cliente, referenciar o nome da paleta no `references/paletas-variacao.md` do cliente
- Imagens de referência visual: `palettes-visual/<nome-do-arquivo>`
